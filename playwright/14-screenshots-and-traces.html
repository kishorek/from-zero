Screenshots, video, and traces

One idea. When a test fails, save a picture and a recording of what happened.

Start with a normal day

Mina runs a check against a website and steps away. The check fails while she is gone.

She opens a saved picture and sees the page as it was.

New words

await and page mean the same as before. The first box is a small script you run yourself. The second box is a setting for the test runner.

screenshot
A picture of the page, written to a file. path is the file name, here page.png.
fullPage
true includes the whole page, including the part below the window.
use
The place in the config file for defaults. defineConfig wraps those settings.
only-on-failure
Take a screenshot when a test fails.
trace
A saved recording of the steps, the page, and the requests. on-first-retry records one when a failed test runs again.
video
A moving picture of the test. retain-on-failure keeps that video when a test fails.

The steps, before any program

  1. Save a picture of the whole page.
  2. When a test fails, keep a picture from that run.
  3. When a failed test runs again, keep a trace.
  4. When a test fails, keep a video too.

The program only writes those steps down.

The same steps, written as a program

Read the steps once more. The two boxes below write those steps down. The first box takes a picture. The second box is a piece of the shared settings.

What each line is saying

  1. await page.screenshot({ path: "page.png", fullPage: true });Save a picture of the whole page in the file page.png. This line waits until the file is written.
  2. console.log("Wrote page.png");Show a short note that the picture was written.
  3. screenshot: "only-on-failure",In the shared settings, take a picture when a test fails.
  4. trace: "on-first-retry",Record a trace when a failed test runs again.
  5. video: "retain-on-failure",Keep a video when a test fails.

Playwright can write an HTML report, a results page from the run. That page can include the picture and the trace.

npx runs a tool from the project. The command npx playwright show-report opens the report.

Try it

Press Take picture. A small copy of the page appears.

Practice. Take one picture of this small page.

Easy to mix up

  • Pictures of passing tests pile up. A picture of a failure is the one you open.
  • A picture can show private customer details. Leave those pictures out of the shared project.
  • The error names the failed check. The picture shows the page, so look at the picture before you rewrite the test.

Remember

When a test fails, keep a picture, a trace, or a video. Open the report and look before you rewrite the test.
