What Playwright is

One idea. Playwright is a helper that can drive three kinds of browser.

Start with a normal day

You hand a driver the same directions every time: open this address, read the heading, come back. The driver can sit in three different cars. You do not learn three sets of pedals.

Playwright is the driver. The cars are three browser families. This page only learns their names. Installing them comes in a later lesson.

New words

Playwright
A helper you add to Node.js. Your script asks it to open a browser and use the page.
library
A box of ready-made functions. You install the box, then call the functions by name.
Chromium
One browser family. Chrome and Edge belong to it.
Firefox
A second browser family. Its own program, with its own habits.
WebKit
A third browser family. Safari belongs to it.
engine
The program that draws the page. Playwright drives the engine. Playwright is not itself the browser.
headless
The browser runs with no window on the screen. The actions are the same. headless: false shows the window when you want to watch.
array
A list in square brackets. This list holds the three names.
for...of
Walk the list one name at a time. const engine is the name for this lap.
+
Between pieces of text, the plus sign glues them into one sentence.

The steps, before any program

  1. Write down the three browser names: chromium, firefox, webkit.
  2. For each name, print one sentence: Playwright can drive that name.
  3. Stop. These steps do not open a window.

The same steps, written as a program

The list is step 1. The loop is step 2. Nothing here launches a browser. That waits until Playwright is installed.

What each line is saying

  1. const engines = ["chromium", "firefox", "webkit"];The three names, in a list. One set of directions can name any of them.
  2. console.log("Playwright can drive " + engine + ".");One sentence per name. The loop variable engine holds whichever name this lap is on.

Try it

Match each word to its job, then press Check.

Practice. Language is JavaScript. Runtime is Node.js. Library is Playwright.

Easy to mix up

  • Playwright drives a browser. The browser itself is a separate download, covered in the install lesson.
  • Chromium, Firefox, and WebKit are three programs. A pass in Chromium says what Chromium did. Safari uses WebKit, so Safari questions get a WebKit run.
  • The script inside the website is a third program. Playwright sits outside that page and drives it.

Remember

Playwright is the driver. Chromium, Firefox, and WebKit are the three cars. Headless means the car runs with no window. The same directions work for all three.
