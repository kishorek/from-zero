What Playwright is

The idea

Playwright is an open source project from Microsoft. You install it with npm. Your Node.js script asks Playwright to launch a browser, and Playwright speaks to that browser through a debugging channel.

The same script can target three engine families: Chromium (the family Chrome and Edge belong to), Firefox, and WebKit (the family Safari belongs to). You write the actions once. A setting chooses the browser.

Playwright also waits for elements to be ready before it clicks, and it includes a test runner that reports pass and fail. You will install that runner in a few lessons. This lesson is only the map.

Why it matters

Names pile up fast: Playwright, Playwright Test, Chromium, a “headless” browser. Headless means the browser runs without a visible window. The actions are the same. You choose a window with headless: false when you want to watch.

A picture to hold

A qualified driver who can drive three models of car. Your directions stay in one language. The driver handles the pedals for whichever car you handed over the keys to. Playwright is the driver. Chromium, Firefox, and WebKit are the cars.

Line by line

  1. const engines = ["chromium", "firefox", "webkit"];The three browser engines Playwright supports with one API. An API is the set of function names you are allowed to call.
  2. console.log("Playwright can drive " + engine + ".");One sentence per engine. The real launch comes after installation. Today you are learning the names.

Try it yourself

Write one sentence, in a comment, that uses all three of these words correctly: language, runtime, library. A solid version: JavaScript is the language, Node.js is the runtime, Playwright is a library that Node.js can import.

Common mistakes

  • Calling Playwright a browser. It drives browsers. You still install browser binaries, which the install lesson does.
  • Assuming a passing Chromium run guarantees Safari. WebKit is a separate engine. Run it when Safari behavior matters.
  • Confusing Playwright with the JavaScript already inside the website you are visiting. They are different programs.

Recap

Playwright is a Node.js library that drives Chromium, Firefox, and WebKit. Headless means no window. The same actions work in all three engines.
