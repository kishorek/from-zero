What browser automation is

One idea. Browser automation is a written list of things a program will do in a browser.

Start with a normal day

You write a card for a careful assistant. Open this address. Read the heading. Close the page.

The assistant can use the mouse and read the screen. The assistant follows the card. A similar-looking button is a different button if the card named another one.

The assistant stands outside the page. JavaScript that lives inside the page is a different job. Asking a server for the raw page, with fetch, never sees a button that appears only after the page’s own script runs.

New words

This page does not open a browser yet. It writes the card as data, so you can see the list before a tool carries it out.

browser automation
A program uses a browser the way a person would: open, click, type, and read.
URL
The address of a page, such as https://example.com.
array
A list, written in square brackets.
object
One form of named blanks, written in curly braces. Here each form is one action.
for...of
Take each item in the list and run the steps inside the braces.
??
If the value on the left is missing, use the value on the right.
fetch
Ask another computer for the page’s text. It does not click, and it does not see buttons the page adds later.

The steps, before any program

  1. Open https://example.com.
  2. Read the heading.
  3. Close.
  4. Show each action’s verb, and its detail when it has one.

Three actions. The program stores them, then walks the list.

The same steps, written as a program

Read the four steps again. Each object is one action. do is the verb. url or what is the detail.

What you should see
open https://example.com
read heading
close

What each line is saying

  1. const steps = [Start a list of actions. Each item is one form.
  2. { do: "open", url: "https://example.com" },The first action. The verb is open. The detail is an address.
  3. console.log(step.do, step.url ?? step.what ?? "");Show the verb, then the detail. If url is missing, use what. If that is also missing, show nothing extra. Close has no detail, so the line shows only close.

Try it

The box already has a click between read and close. Press Run. You should see open, read, click, close, in that order.

Practice. Four verbs, in this order: open, read, click, close.

Easy to mix up

  • A goal such as “make sure the site works” is not a script. The script is the list of actions.
  • fetch receives the text the server sent. A browser also runs the page, so it can see a button that appears later.
  • Point the assistant only at a site whose owner agreed. Permission is part of the task.

Remember

Browser automation is a program using a browser: open, act, read, close. The script is that list. It stands outside the page.
