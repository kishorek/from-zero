Installing Playwright

One idea. Install Node, the test runner, and the browsers. The package alone is not a browser.

Start with a normal day

A driving lesson needs two things: the textbook, and a car. Buying the textbook does not put a car in the driveway.

Node.js is the building you already have. The test runner is the textbook. The browsers are the cars. You collect all three before the first drive.

New words

Node.js 20
The version this course needs. node -v prints it. A number starting at 20 or higher is enough.
npm init playwright@latest
The starter command. It asks four questions, then writes the project and downloads the browsers.
JavaScript
The spelling this course uses. The starter also offers TypeScript, a stricter spelling. Choose JavaScript.
tests
The folder where test files live. Tell the starter to use that name.
GitHub Actions
An automatic check that runs on GitHub. Skip it for this course.
package.json
The project’s list of tools. The starter writes it for you.
@playwright/test
The test runner. It starts the browser, runs each test, and reports pass or fail. It uses the playwright library.
npm i -D
Install a tool for building and testing. The manual steps are npm init -y, then npm i -D @playwright/test, then npx playwright install.
npx
Run a command from a package you just installed.
browser binary
The real browser program, saved on your disk. npx playwright install downloads it. The npm package alone does not include it.
import
Load a tool from a package. chromium is Playwright’s name for the Chromium family.
executablePath()
The folder path of the Chromium program Playwright will launch. A real path means the browsers were downloaded.
"type": "module"
A line you can add to package.json so import works in an ordinary script.

The steps, before any program

  1. Make a folder named playwright-lab and step into it.
  2. Run npm init playwright@latest. Answer: JavaScript, a tests folder, no GitHub workflow, yes to browsers.
  3. Run node -v and read a version of 20 or newer.
  4. A small script loads Playwright and prints where Chromium was saved.

The same steps, written as a program

The first block is the terminal. The second block is the check. If the import fails, you are outside the project folder, or the install did not finish.

What each line is saying

  1. npm init playwright@latestRun the starter. Answer JavaScript, tests, no GitHub workflow, yes to browsers.
  2. import { chromium } from "playwright";Load Chromium’s name from the library. This file is a script. A test file imports from @playwright/test instead.
  3. console.log(chromium.executablePath());Print where the Chromium program was saved. A real folder path means the browsers arrived.

Try it

Press the button once per step. This picture is the install. The real commands are the four lines above.

Practice. Node, a folder, the runner, then the browsers.

Easy to mix up

  • Node.js 18 is too old for the current runner. node -v needs to start at 20.
  • After a manual npm i, the runner is on the list and the browsers may still be missing. npx playwright install downloads them.
  • The starter’s TypeScript choice expects different files. This course is JavaScript, so choose JavaScript.

Remember

Install the runner, then install the browsers. npm init playwright@latest does both. Node.js 20 or newer is the version this course uses.
