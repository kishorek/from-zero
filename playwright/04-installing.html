Installing Playwright

The idea

You need Node.js 20 or newer. In an empty folder, the official starter is npm init playwright@latest. It asks four things. Choose JavaScript, not TypeScript. Put tests in tests. Skip the GitHub Actions workflow for this course. Say yes to installing browsers.

That command writes package.json, a config file, an example test, and it downloads browser binaries. Those binaries are the actual browsers Playwright will launch. The npm package alone is not enough.

If you prefer to see each step, the manual version is npm init -y, then npm i -D @playwright/test, then npx playwright install. @playwright/test is the test runner. It depends on the playwright library. npx runs a command from the packages you installed.

Why it matters

A missing browser binary looks like a broken test. It is an incomplete install. Separating “install the library” from “install the browsers” makes that message readable.

A picture to hold

Buying a driving textbook and also renting the cars. npm i -D @playwright/test is the textbook. npx playwright install collects the cars. You need both before the first lesson on the road.

A small example

executablePath() prints where Chromium was downloaded. If this import fails, you are not in the project folder, or the install did not finish. Add "type": "module" to package.json so this course’s import lines work in ordinary scripts.

Line by line

  1. npm init playwright@latestRun the starter. Answer JavaScript, tests, no workflow, yes to browsers.
  2. import { chromium } from "playwright";Load the browser type from the library. This file is a script, not a test. Tests import from @playwright/test instead.
  3. console.log(chromium.executablePath());Ask which Chromium binary will launch. A real filesystem path means the browsers were installed.

Try it yourself

Complete the install. Run npx playwright --version and node check.mjs. Both should print without an error. Then run npx playwright test once, even before you study the example test. A passing or a clearly reported run means the runner works.

Common mistakes

  • Installing Node.js 18 or older. Current @playwright/test requires Node.js 20 or newer.
  • Forgetting npx playwright install after a manual npm i. The library is present and the browsers are not.
  • Choosing TypeScript in the starter and then pasting these JavaScript files unchanged. This course stays in JavaScript. Pick JavaScript.

Recap

Install @playwright/test, then install the browsers. npm init playwright@latest does both and writes a project. Node.js 20 or newer is required.
