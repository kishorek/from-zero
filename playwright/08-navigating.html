Navigating

The idea

page.goto(url) opens an address and waits until the load event, unless you change waitUntil. After that, page.url() is the address you actually landed on, which might differ if the site redirected you. page.title() is the document title.

reload loads the same address again. goBack walks history, like the browser’s back button. Prefer waiting for a specific fact afterward (toHaveURL, a heading) over waiting for the network to go quiet.

Why it matters

Every flow starts with navigation. The subtle part is knowing which moment counts as “arrived.” Waiting for the load event is a good default. Waiting for networkidle is a habit Playwright’s own docs discourage, because busy sites never go idle and quiet sites idle too early.

A picture to hold

Walking into a building and stopping in the lobby when the door shuts (the load event). You have arrived. People may still be moving inside. Check the sign in the lobby (the heading) before you declare you are in the right room.

A small example

Line by line

  1. await page.goto("https://example.com");Navigate. The promise fulfills on the load event by default.
  2. await expect(page).toHaveURL("https://example.com/");The final slash is part of this site’s address. A mismatch fails the test with both URLs printed.
  3. await expect(page).toHaveTitle("Example Domain");The title lives in the document, not in the address bar. Check the one you mean.
  4. await page.reload();Ask for the same document again, and wait for load again.

Try it yourself

After goto, click the “Learn more” link with page.getByRole("link", { name: "Learn more" }).click(), which the locators lesson will explain in full. Then expect the URL to match /iana.org/. goBack(), and expect the title Example Domain again.

Common mistakes

  • Passing waitUntil: "networkidle" as a default. Use it only when you have a measured reason. Prefer a visible fact.
  • Comparing page.url() with a string that forgot the trailing slash or the https.
  • Calling goto and then immediately reading the page with no await. You are early.

Recap

goto opens an address and waits for load. Check toHaveURL and toHaveTitle. reload and goBack move again. Prefer a visible fact over a quiet network.
