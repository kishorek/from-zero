Navigating

One idea. Open an address, read the sign in the lobby, then come back.

Start with a normal day

You walk into a building. You stop in the lobby when the door shuts behind you. People may still be moving in the rooms. You read the sign in the lobby before you decide you are in the right place.

The door shutting is the page finishing its first load. The sign is the title, or the address in the bar. Reload asks for the same door again. Back walks out to the place you came from.

New words

goto
page.goto(url) opens that address and waits until the document has loaded.
load
The door-shut moment. The document and its immediate files have arrived. waitUntil can choose a different moment. This lesson keeps the usual one.
url()
The address you actually landed on. A site can send you somewhere else on the way in.
title()
The document title. It lives in the page, not in the address bar.
toHaveURL
A check that the address matches. This site’s address includes a final slash: https://example.com/.
toHaveTitle
A check that the document title matches the text you wrote.
reload
Open the same address again, and wait for load again.
goBack
The browser’s Back button. It returns to the previous address in this tab.
await
Pause until that open, reload, or check has finished.
networkidle
A different wait: “the network looks quiet.” Busy sites may never get there. This lesson does not use it. Read a sign instead.

The steps, before any program

  1. Open https://example.com and wait until it has loaded.
  2. Check the address, including the final slash.
  3. Check the title: Example Domain.
  4. Reload the page, and check the title again.

The same steps, written as a program

Each line is one of those steps. expect reads the sign after you arrive. Run it with npx playwright test.

What each line is saying

  1. await page.goto("https://example.com");Open the address and wait until the document has loaded.
  2. await expect(page).toHaveURL("https://example.com/");The final slash is part of this site’s address. A mismatch prints both addresses.
  3. await expect(page).toHaveTitle("Example Domain");The title lives in the document. The address bar is a different sign.
  4. await page.reload();Ask for the same document again, and wait for load again.

Try it

Click Learn more, then press Back.

Practice. Learn more changes the address. Back returns to example.com.

Easy to mix up

  • networkidle waits for a quiet network. The usual wait is the load, then a visible fact such as the title.
  • The address to check includes https and, on this site, the final slash.
  • goto needs await. The next line otherwise reads the page before the door has shut.

Remember

goto opens an address and waits for load. Check the address and the title. reload and Back move again. Read a sign on the page.
