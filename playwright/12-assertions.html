Assertions

One idea. A check can keep looking until the words on the page are right.

Start with a normal day

Asha sends a form on a website. The page still says Waiting.

She watches the status until the word changes to Submitted.

New words

import, test, async, await, and page mean the same as before. expect on a locator can keep looking.

setContent
Replace the tab with page text written inside the check. Backticks wrap text that covers more than one line.
data-testid
An extra name put on an element for a test. Here the name is status. getByTestId finds it. The result is a locator.
setTimeout
Inside the page, change the text after a short delay. 200 is that delay in thousandths of a second. textContent is the text inside the element.
toHaveText
Keep checking until the element’s whole text matches these words.
check once
Read the text a single time and decide immediately. A practice button does this.
keep looking
Read again and again until the text is right, or time runs out.

The steps, before any program

  1. Open a page whose status says Waiting.
  2. Let the page change that word to Submitted.
  3. Keep looking until the status shows Submitted.

The program only writes those steps down.

The same steps, written as a program

Read the steps once more. The box below is those same steps. The last line keeps looking until the status says Submitted.

What each line is saying

  1. <p data-testid="status">Waiting</p>The status starts as the word Waiting. The test id status is how the check finds it.
  2. textContent = "Submitted"A moment later, the page changes that word to Submitted. The change is in the page’s own script.
  3. await expect(page.getByTestId("status")).toHaveText("Submitted");Keep looking until the whole status text is Submitted. await makes the test wait for that looking.

A check on a locator keeps looking. A check on text you already copied looks one time.

Try it

Press Reload, then Check once now, then Keep looking. Keep looking is the check that sees Submitted.

Practice. The status changes to Submitted a moment after load.

Status: Waiting

Easy to mix up

  • This check wants the whole text. Extra words around Submitted make it fail.
  • Check the words a person can read. Those words are the result that matters.
  • Put await in front of the check. The test then waits while the check keeps looking.

Remember

A check on a locator keeps looking until the text matches. A check on text you already copied looks one time.
