Auto-waiting

One idea. Playwright waits until a button is ready, then it clicks.

Start with a normal day

Sam opens a website and looks for a Save button. The button is missing at first, then it shows up.

Sam presses it only after it is visible.

New words

import, test, expect, async, await, and page mean the same as in the earlier lessons.

setContent
Replace the tab with page text written inside the check. Backticks, the ` marks, wrap text that covers more than one line.
hidden
A mark that keeps the button out of sight. This button’s id is save.
setTimeout
Inside the page, run code after a short delay. 300 is that delay in thousandths of a second. document.querySelector is the page’s own search for the button.
getByRole
Find an element by its job and the name a person sees. A button is one job. The result is a locator, a description that is searched again when you use it.
click
Press the element. Playwright waits until it is visible and can be pressed.
toBeVisible
Keep checking until the element is on the screen.
fixed wait
A pause of a length you guessed. The practice button Short fixed wait uses one.

The steps, before any program

  1. Open a page where Save is hidden.
  2. Wait until Save is visible and can be pressed.
  3. Press Save.
  4. Check that Save is on the screen.

The program only writes those steps down.

The same steps, written as a program

Read the steps once more. The box below is those same steps, written as a test.

What each line is saying

  1. <button id="save" hidden>Save</button>The Save button starts out of sight. A person cannot press a button they cannot see.
  2. setTimeout(() => {The page shows the button a moment later. That delay lives in the page’s own script.
  3. await page.getByRole("button", { name: "Save" }).click();Find the button named Save and press it. This line waits until the button is ready.
  4. await expect(page.getByRole("button", { name: "Save" })).toBeVisible();Check that Save is on the screen. The check keeps looking until it is.

Ready means the button is on the screen, has stopped moving, and can be pressed.

Try it

Press Load page, then Click when ready. The short fixed wait misses the button if you press it too soon.

Practice. Load the page. Save shows up after a short wait.

Easy to mix up

  • A fixed wait guesses the timing. The click already waits until the button can be pressed.
  • The button can sit in the page and still be hidden. The click waits until a person could see it.
  • If time runs out, the button never became ready. Read that message before you change the check.

Remember

A click waits until the button is ready. You name the button, and Playwright does the waiting.
