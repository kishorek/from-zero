Frames

One idea. A frame is a page inside the page. Look there before you look for the field.

The idea

An iframe embeds another document inside the page. Locators on page do not see inside that document. page.frameLocator("iframe[title=\"Payment\"]") points at the frame. Locators you call on the frame locator look inside it.

Give the iframe a title in pages you control, and use that title in the frame locator. A CSS description of the frame is reasonable here because you are naming the frame, not the button inside it. The button inside should still use getByRole or getByLabel.

Why it matters

Payment widgets, embedded editors, and some consent dialogs are frames. A test that says the button does not exist, while you can see the button, is often looking in the outer page.

A picture to hold

A shop with a service window cut into the wall. The counter you first walk up to cannot pass a form through the glass. You address the window (frameLocator), then you talk to the person behind it (getByLabel). Two addresses, in that order.

A small example

Line by line

  1. <iframe title="Payment"The outer page owns the frame. title is the accessible name of the frame and a stable handle for tests.
  2. srcdoc="srcdoc supplies the inner document without a second website. The inner document has its own label and input.
  3. const frame = page.frameLocator("iframe[title=\"Payment\"]");Describe the frame. This value is a frame locator, not a page. You call getByLabel on it.
  4. await frame.getByLabel("Card number").fill("4242");The label lookup happens inside the frame. The same lookup on page would not see this input.

Common mistakes

  • Searching the outer page for an element that lives in the frame.
  • Using a long CSS path inside the frame when the inner control has a label.
  • Nesting confusion: a frame inside a frame needs a frame locator from the first frame locator. Walk one level at a time.

Recap

Iframe contents are a separate document. frameLocator selects the frame. Locators on that object look inside it.
