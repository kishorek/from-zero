Frames

One idea. A frame is a page inside the page, so look there for the field.

Start with a normal day

Rita checks out on a website. The card box sits in a small window inside the page.

She looks at that window first, then types in the box.

New words

import, test, expect, await, and page mean the same as before. Here page is the outer tab.

frame
A separate page set inside this page. The iframe tag places it. This one is titled Payment. srcdoc is the inner page, written in place.
frameLocator
Point at that frame by its title. Searches you call on this value stay inside the frame.
getByLabel
Find the field by the words tied to it, here Card number. fill replaces the text. toHaveValue waits until the field holds 4242.
backslash
In quoted text, a backslash in front of a quote keeps that quote as part of the text.

The steps, before any program

  1. Open a page that contains a payment frame.
  2. Point at the frame named Payment.
  3. Find Card number inside the frame and write 4242.
  4. Read the field back and see 4242.

The program only writes those steps down.

The same steps, written as a program

Read the steps once more. The box below is those same steps. The card field is filled inside the frame.

What each line is saying

  1. <iframe title="Payment"The outer page holds a frame named Payment. The card field lives inside that frame.
  2. srcdoc="The inner page is written right here. It contains the label Card number and a box.
  3. const frame = page.frameLocator("iframe[title=\"Payment\"]");Point at the frame whose title is Payment. Later searches on frame look inside it.
  4. await frame.getByLabel("Card number").fill("4242");Inside the frame, find Card number and write 4242. The same search on the outer page misses this box.
  5. await expect(frame.getByLabel("Card number")).toHaveValue("4242");Read the field inside the frame. It should hold 4242.

Try it

Press Look in the page. Then press Look in the frame.

Practice. The card field is in the white frame.

Outer page. No card field here.

Easy to mix up

  • The card field is inside the frame. A search on the outer page misses it.
  • Choose the frame first. The label search then happens inside it.
  • A frame can sit inside another frame. Point at the outer frame, then at the inner one.

Remember

A frame is a separate page inside the page. Point at the frame, then find the field inside it.
