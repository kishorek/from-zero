Your first test

One idea. A test opens a page and checks one fact.

Start with a normal day

A checklist has one line: “The sign on the door says Example Domain.” You walk to the door. You look at the sign. You tick the line, or you leave it blank.

The sentence inside test is that line. expect is the pencil. The runner reads the list and tells you which ticks are missing.

New words

test
One named check. The words in quotes should state a fact, because a failure report quotes them.
expect
The check itself. toHaveTitle looks at the document title and waits until it matches, or until time runs out.
import
Bring test and expect in from @playwright/test, the runner.
async
Marks a function that can pause. await is the pause. It waits until that step finishes.
=>
A short way to write a function. The runner calls this function and passes it a tab.
{ page }
The tab the runner already opened for this test. You do not launch the browser yourself.
goto
Open an address in that tab and wait until the document has loaded.
load
The moment the document and its immediate files have finished arriving. goto waits for that moment.
.spec.js
The ending of a test file. npx playwright test finds files like tests/example.spec.js and runs each test inside.
-g
A filter. npx playwright test -g "title" runs only the tests whose names contain that word.

The steps, before any program

  1. Bring in test and expect.
  2. Name one fact: example.com names itself in the title.
  3. Open https://example.com and wait until it has loaded.
  4. Check that the title is Example Domain.

The same steps, written as a program

Four lines. The name is the fact. goto walks to the door. expect reads the sign. Run it with npx playwright test tests/example.spec.js.

What each line is saying

  1. import { test, expect } from "@playwright/test";test names the check. expect performs it.
  2. test("example.com names itself in the title", async ({ page }) => {The name is a fact. A failure report quotes this sentence.
  3. await page.goto("https://example.com");Open the address and wait until the document has loaded.
  4. await expect(page).toHaveTitle("Example Domain");Keep looking until the title matches, or until time runs out. This site is fast enough for the usual limit.

Try it

Press Run test. Then type a wrong title and run it again so you can see a failure. Put Example Domain back.

Practice. Example Domain passes. Any other title fails.

Easy to mix up

  • A name like test 1 tells you nothing when it fails. Name the fact.
  • await belongs in a function marked async. Without that mark, the file is a syntax error.
  • Each test receives its own page from the runner. Sharing one tab by hand mixes the tests together.

Remember

A test opens a page and checks one fact. npx playwright test runs the files in tests. Name the test after the fact.
