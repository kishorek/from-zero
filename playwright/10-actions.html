Layer 03 · Lesson 10 of 20

Actions

One idea. A click presses. Filling a box replaces everything already in it.

Start with a normal day

You see a link that says Learn more. You press it. Then you look at the address bar to see whether you moved.

A form field is a different hand movement. You clear the box and write the whole answer. You do not tap the letters one by one unless that box is listening for each key.

New words

locator
A way to point at one thing on the page, checked again when you use it. getByRole("link", { name: "Learn more" }) points at the link whose visible name is Learn more.
click
Press that thing. await waits until the press has been sent and the navigation it caused has settled.
fill
Clear an input and put the whole value in. This is the usual verb for a text field. The practice box below uses that idea.
press
Send one key, such as Enter.
check
Tick a checkbox. uncheck clears it.
selectOption
Choose one entry from a dropdown menu, the <select> element.
await
Pause until that verb finishes. A click without await lets the test end while the press is still happening.
toHaveURL
Check the address after the click. /iana\.org/ is a pattern: slashes wrap it, and \. means a real dot. The address should contain iana.org.
hidden
Playwright will not press a control that is hidden, switched off, or still moving. The next lesson explains that wait. This lesson is the verbs.

The steps, before any program

  1. Open https://example.com.
  2. Find the link named Learn more.
  3. Click it.
  4. Check that the address now contains iana.org.

The same steps, written as a program

Find the link, then call click. The other verbs use the same shape: point at the control, then call fill, press, check, or selectOption. This file shows the click.

What each line is saying

  1. await page.goto("https://example.com");Start on a page that contains the link.
  2. getByRole("link", { name: "Learn more" }).click()Point at the link, then press it. await waits until the press has landed and the new page has settled.
  3. await expect(page).toHaveURL(/iana\.org/);The address should now contain iana.org. The check is about the page you landed on.

Try it

Type a note, press Save, and read the line the page shows. Change the note and save again. The new text replaces the old text.

Practice. Saving writes the whole note. A second save replaces it.

Easy to mix up

  • fill is the usual verb for a normal text field. pressSequentially is for a field that listens to each key.
  • A locator that matches two buttons stops and says so. Add more of the visible name so one button remains.
  • click() needs await. The test otherwise ends while the press is still happening.

Remember

Point at the control, then call the verb: click, fill, check, press, or selectOption. await it. Then check what changed on the page.
