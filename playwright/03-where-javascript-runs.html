Browser JavaScript, Node.js, and Playwright

One idea. The page, Node.js, and Playwright are three different rooms.

Start with a normal day

You are watching a play from the booth. The actors on stage have their own script. That script can move the props on stage. It cannot open the filing cabinet in the booth.

Your notes live in the booth. They can open the cabinet. They cannot pick up a prop unless you ask the stage manager. Playwright is that stage manager: your Node.js script, driving a browser from outside the page.

New words

page JavaScript
The script that lives inside the website. It can read and change that page. The browser keeps it away from your files.
Node.js
Your script on your computer. It can read files. By itself it cannot see a web page.
Playwright
Your Node.js script driving a separate browser. The page may also be running its own script. Two programs at once.
window
A name that exists in a browser page. It does not exist in Node.js.
typeof
Ask what kind of thing a name is. On a missing name the answer is "undefined", so the line does not crash.
? :
A short choice. test ? "yes" : "no" picks the first answer when the test is true, and the second answer otherwise.
document
The page’s own handle on itself. It exists in the page. It does not exist in your test file.
page
Playwright’s handle on the tab. It exists in your test. It does not exist inside the page.
page.evaluate
Ask the page to run a small snippet. That snippet is in the page’s room, so it may use document. Use this rarely. Later lessons look at the page the way a person does.

The steps, before any program

  1. Ask whether the name window exists.
  2. If it is missing, this file is running in Node.js.
  3. If it exists, this file is running in a browser page.
  4. Print one sentence that names the room.

The same steps, written as a program

One question, then one sentence. Run it with Node and the sentence names Node.js. The same line in a browser console would name the page.

What you should see
This file is running in Node.js.

What each line is saying

  1. typeof window === "undefined"Ask whether window exists. In Node.js the answer is the text "undefined".
  2. ? "Node.js" : "a browser page"Pick the first label when the test is true. Pick the second label when the test is false.
  3. console.log("This file is running in " + room + ".");Print the label. In Node.js the sentence names Node.js.

Easy to mix up

  • In the test file, the handle is page. document belongs inside the page.
  • A snippet passed to page.evaluate runs in the page. There, page does not exist. document does.
  • The page and the test keep separate variables. A value moves only when your script passes it across.

Remember

The page sees the page. Node.js sees your files. Playwright is Node.js driving a browser from the booth. window tells you which room a file is in.
