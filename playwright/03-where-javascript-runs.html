Browser JavaScript, Node.js, and Playwright

The idea

Keep three rooms separate. In the page, JavaScript can read and change that page, and the browser stops it from freely reading your disk. In Node.js, your script can read files and the network, and it cannot see a page. In a Playwright run, a Node.js script drives a separate browser. The page may also be running its own JavaScript. Those are two programs at once.

Playwright can ask the page to run a snippet, with page.evaluate. Use that rarely, when you truly need a value from inside the page. Prefer locators and assertions, which look at the page the way a person does.

Why it matters

The most common early bug is pasting document.querySelector into a test, or pasting page.getByRole into a web page. Each call belongs in one room.

A picture to hold

A stage play. The actors on stage have the script inside the play (page JavaScript). You sit in the booth with a prompt book (your Node.js test). Playwright is the stage manager who can cue the lights and listen to a line. You are not on stage, even though you can hear it.

A small example

What you should see
This file is running in Node.js.

Line by line

  1. typeof window === "undefined"window exists in a browser page and does not exist in Node.js. typeof on a missing name is "undefined", which avoids a crash.
  2. ? "Node.js" : "a browser page"A conditional expression. When the test is true, the result is "Node.js". Otherwise it is the other string.
  3. console.log("This file is running in " + room + ".");Run in Node.js, the sentence names Node.js. The same line in a browser console would name the page.

Try it yourself

Add a second log: console.log(typeof process). In Node.js it prints object. If you paste only that line into a browser console, it prints undefined. Write down both results. That pair is the whole distinction.

Common mistakes

  • Using document in the test file. In the test file, you use page.
  • Using page inside page.evaluate. The snippet inside evaluate runs in the page, where page does not exist. It may use document.
  • Assuming the page and the test share variables. They do not. Values cross only when you pass them.

Recap

Page JavaScript sees the page. Node.js sees files. Playwright is Node.js driving a browser from outside. window tells you which room a file is in.
