Pages and popups

The idea

A link with target="_blank", or a script that calls window.open, creates another page. In Playwright that other page arrives as a popup event on the current page. You must start waiting before the click. If you click first, the popup can happen before you began listening, and the wait misses it.

The pattern is: create the promise with page.waitForEvent("popup"), then click, then await the promise. The result is a Page. You assert on that page the same way you assert on any page.

Why it matters

Help windows, OAuth windows, and “open in a new tab” links all use this shape. The ordering bug is so regular that it deserves its own lesson.

A picture to hold

Holding your hands out before someone tosses you a key. If you put your hands out after the toss, the key is already on the floor and your wait is for a second toss that will not come.

A small example

Line by line

  1. target="_blank"Ask the browser to open the link in a new tab. That new tab is the popup Playwright will hand you.
  2. const popupPromise = page.waitForEvent("popup");Start listening. Do not await yet. You want the listener armed before the click.
  3. await page.getByRole("link", { name: "Open help" }).click();Now cause the popup.
  4. const popup = await popupPromise;Receive the new Page. It has its own URL, locators, and assertions.
  5. await expect(popup).toHaveTitle("Example Domain");Assert against the new page, not the original one. The original page still shows the link.

Try it yourself

Log page.url() and popup.url() after the wait. They differ. Then reverse the order on purpose: click, then start waitForEvent. See the timeout. Restore the original order. The failure is the lesson.

Common mistakes

  • Awaiting waitForEvent before the click. That line never returns, because the click has not happened, so the event never arrives.
  • Asserting the title on page when the title changed on popup.
  • Closing the context and expecting the popup to survive. The popup lives in the same context.

Recap

Start waitForEvent("popup") before the click that opens a tab. Await it after the click. The value is another page.
