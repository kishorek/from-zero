Pages and popups

One idea. Start listening for the new tab before the click that opens it.

Start with a normal day

Jon uses a help link on a website. He gets ready to catch a new tab.

Then he clicks the link. The new tab arrives, and he can read it.

New words

import, test, expect, await, page, and getByRole mean the same as before.

setContent
Replace the tab with a small page written inside the check. href is the address a link points to. target="_blank" asks the browser to open that link in a new tab.
popup
That new tab. Playwright hands it to you as another page.
waitForEvent
Start listening for "popup". The result is a promise, work that finishes later. You start listening, then click, then await the new tab.
click
Press the link. This is the click that opens the new tab, so the listener is already waiting.
toHaveTitle
Keep checking until the new tab’s title matches these words.

The steps, before any program

  1. Get ready to catch a new tab.
  2. Click the link that opens help.
  3. Take the new tab when it arrives.
  4. Read the title of that tab.

The program only writes those steps down.

The same steps, written as a program

Read the steps once more. The box below is those same steps. Listening starts on the line before the click.

What each line is saying

  1. target="_blank"This link asks the browser for a new tab. The words Open help are what a person clicks.
  2. const popupPromise = page.waitForEvent("popup");Start listening for that new tab. Save the listening in a name, and click on the next line.
  3. await page.getByRole("link", { name: "Open help" }).click();Click the link named Open help. That click opens the new tab.
  4. const popup = await popupPromise;Now wait for the new tab, and name it popup. popup is another page, with its own address.
  5. await expect(popup).toHaveTitle("Example Domain");Check the title of the new tab. The first page still shows the link.

Try it

Press Hands out, then click. Then press Click, then put hands out.

Practice. Try hands out first. Then try the other order.

Easy to mix up

  • If you wait for the new tab before the click, the click never runs. Start listening, click, then await.
  • Check the title on the new tab. The first page still shows the link.
  • The new tab lives in the same browser session. Closing that session closes the tab.

Remember

Start listening for the popup before the click. Await that listening after the click, and you receive the new page.
