Layer 03

Playwright

Playwright lets a program drive a real browser: open pages, click, type, and check what a person would see. These twenty lessons assume you finished the earlier practice boxes. When a lesson needs you to wait for the browser, it explains that wait in ordinary words first. The demos are pretend pages. You do not need a working install to use them.

Use a site and an account you are allowed to automate. The examples use example.com and pages the check builds itself, so you can learn the tool without touching anyone else’s login.
