Browser, context, and page

The idea

Playwright splits the browser into three objects. The browser is the running application. A browser context is an isolated profile: its own cookies, its own storage, like a fresh guest window. A page is one tab inside a context.

In the runner you usually receive page and never mention the other two. They are still there. The page fixture’s context is new for every test, which is why tests do not leak logins into each other. When you need a second tab, you ask the context for another page.

Why it matters

Two tests that secretly share cookies will pass alone and fail together, or the reverse. Isolation is the reason the context exists. Knowing the three nouns makes later lessons (popups, saved login) fit a picture you already have.

A picture to hold

A hotel. The browser is the building. A context is a guest room with its own key and an empty minibar. A page is a desk in that room. Guests do not share minibars unless you handed them the same key on purpose.

A small example

What you should see
Example Domain

Line by line

  1. const browser = await chromium.launch();Start the building. One operating-system process appears.
  2. const context = await browser.newContext();Open a guest room. Cookies set in this context stay in this context.
  3. const page = await context.newPage();Open a tab in that room. Most actions (goto, click, locators) happen on the page.
  4. await context.close();Close the room, which closes its tabs. Closing the browser next shuts the building.

Try it yourself

Create two contexts. In each, open a page to https://example.com and print the title. Then close both contexts and the browser. You have just run two isolated sessions in one process. In the runner, you get that isolation without writing these lines.

Common mistakes

  • Storing cookies in one test and expecting the next test to see them. Each test has a new context.
  • Calling browser.newPage() in old examples you find online. Current code creates a context, then a page, so the isolation is visible. The runner’s page fixture already follows that shape.
  • Closing the browser and then using the page. The tab is gone. Close at the end.

Recap

Browser, then context, then page. A context is a clean profile. Tests get a fresh context so they do not share cookies.
