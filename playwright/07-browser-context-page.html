Browser, context, and page

One idea. The browser is the building. Each room has its own key. A page is one desk in that room.

Start with a normal day

A hotel has a building, rooms, and desks. Guests in room A leave a note in the minibar. Guests in room B open their own minibar and find it empty.

A cookie is that note. Each test gets a new room, so a login saved in one test stays in that test.

New words

browser
The running browser program. chromium.launch() starts one. One program appears on the computer.
context
A private room inside that browser. Its own cookies, its own saved site data. browser.newContext() opens one. A fresh guest window is the same idea.
page
One tab, which is one desk in that room. context.newPage() opens it. goto, clicks, and reading the title happen on the page.
cookie
A small note a site stores in the room, such as “this person is signed in.” A different context does not see it.
await
Pause until that step finishes. The top of a library script may use it because the file is run as a module.
import
Load chromium from the playwright library. This file is a script, so you start and close the browser yourself.
title()
The document title, the words on the tab. For example.com that is Example Domain.
close()
context.close() shuts the room and its tabs. browser.close() shuts the building.
fixture
A tool the test runner sets up for you. In a test you usually receive page and never write launch. That page already sits in a new context.

The steps, before any program

  1. Start Chromium. That is the building.
  2. Open a new context. That is an empty room.
  3. Open a page in that room and go to https://example.com.
  4. Print the title.
  5. Close the room, then close the browser.

The same steps, written as a program

Five actions, in that order. In the test runner you only see the page. The room and the building are still there, opened for you.

What each line is saying

  1. const browser = await chromium.launch();Start the building. One browser program appears.
  2. const context = await browser.newContext();Open a guest room. A cookie saved here stays in this room.
  3. const page = await context.newPage();Open a tab in that room. Going to an address, clicking, and reading the title happen on the page.
  4. await context.close();Close the room, which closes its tabs. The next line closes the building.

Try it

Save a cookie in room A, then look in room B.

Practice. Save a note in room A. Room B’s minibar stays empty.

Easy to mix up

  • A cookie saved in one test stays in that test. The next test gets a new room, so the note is not there.
  • Older examples call browser.newPage() directly. The shape here is browser, then context, then page, so the room is visible. The runner’s page already sits in a fresh room.
  • Close at the end. After browser.close(), the tab is gone.

Remember

Browser, then context, then page. A context is a clean room with its own cookies. Each test gets a new room.
