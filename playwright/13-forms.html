Forms

The idea

A form control should have a label. getByLabel("Your name") finds the input connected to that label text. getByRole("textbox", { name: "Your name" }) is the same idea, said through the role.

fill sets a text field. check ticks a checkbox. selectOption picks a value in a dropdown, by the value or by the visible label. Then assert the value that stuck, with toHaveValue or toBeChecked, and assert whatever the form did next.

Why it matters

Forms are where automation does real work: search boxes, settings, checkout on a site you own. Labels are also how a person finds the field. A test that uses the label documents the form.

A picture to hold

A paper form on a clipboard. You do not say “write in the third rectangle.” You say “write beside Your name.” getByLabel is that sentence. fill is writing the answer in one motion.

A small example

Line by line

  1. <label>Your name <input name="name" /></label>Wrapping the input in a label connects them. getByLabel("Your name") depends on that connection, which is also what makes the form usable.
  2. await page.getByLabel("Your name").fill("Asha");Replace the field’s value with Asha.
  3. await page.getByLabel("Subscribe").check();Tick the checkbox. check leaves it checked even if it was already checked. click would toggle, which is a different intention.
  4. await page.getByRole("button", { name: "Save" }).click();Press the button that submits, here by running the page’s own listener.
  5. await expect(page.getByText("Saved Asha")).toBeVisible();Confirm the outcome a person would read, not only the click.

Try it yourself

Add a <select> with two options, Tea and Milk. Select Milk with selectOption({ label: "Milk" }). Assert toHaveValue. If you used values distinct from labels, notice that toHaveValue checks the value attribute, and choose the assertion that matches what you set.

Common mistakes

  • Locating inputs by a CSS name that the designer will rename, when a visible label already exists.
  • Using click on a checkbox when you mean “make it checked.” check states the goal.
  • Filling a field and never asserting the value. A silent no-op looks like success.

Recap

Find fields with getByLabel or a named textbox role. fill, check, and selectOption set them. Assert the value and the visible result.
