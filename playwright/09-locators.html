Locators

One idea. Find a thing on the page by its job and the words on it.

Start with a normal day

You ask a stranger for “the door labeled Exit.” You do not say “the third rectangle from the left.”

The building can be repainted. The job of the door, and the word on it, stay useful.

On a page, the job might be heading, link, or button. The words are what a person can read.

New words

The program looks for a heading and a link. Read these words before the spelling.

element
One thing on the page: a heading, a link, a button, a box.
locator
A description of that thing. Each time you use it, Playwright looks again. It is not a photo taken five seconds ago.
role
The job. heading is a title. link is something a person can follow. button is something a person can press.
accessible name
The name a screen reader would say. For a heading or a link, it is usually the visible text. For a box, it is usually the label.
getByRole
Find something by its job and its name. page.getByRole("heading", { name: "Example Domain" }) means “the heading whose name is Example Domain.”
await
Pause this step until the browser finishes it.
async and =>
async marks a function that uses await. => is a short way to write a function.
expect
A check. toBeVisible() means a person could see it. The check keeps looking for a short time.
href
The address a link points at.

The steps, before any program

  1. Open https://example.com.
  2. Find the heading named Example Domain.
  3. Find the link named Learn more.
  4. Check that the heading is visible, and that the link’s address mentions iana.org.

The program writes those four steps. It finds things the way the stranger finds the Exit door.

The same steps, written as a program

Read the four steps again. The first lines only borrow test and expect from Playwright. The getByRole lines are the “door labeled Exit” requests.

What each line is saying

  1. page.getByRole("heading", { name: "Example Domain" })Find the heading whose visible name is Example Domain. A heading is the title on the page.
  2. page.getByRole("link", { name: "Learn more" })Find the link whose text is Learn more.
  3. await expect(heading).toBeVisible();Check that a person could see that heading. The check waits a moment if the page is still drawing.
  4. toHaveAttribute("href", /iana\.org/)Read the link’s address and ask whether it contains iana.org. The slashes wrap a pattern. The backslash says the dot is a real dot.

Other ways to point

getByLabel finds a box by the label a person can see. That is the next spelling to reach for.

A path through the page’s tags, such as “the second span inside the third div,” breaks when someone wraps that span. Use it only when the page has no job and no words you can name.

Try it

Press Find. The heading named Example Domain should match. Then change the name to Example and press Find again. That shorter name misses.

Practice. Role is the job. Name is the words a person sees.

Example Domain

Learn more

Easy to mix up

  • A path through tags is precise about structure, and structure changes. A job and a name survive a repaint.
  • A locator looks again every time you use it. An old saved handle can point at a thing that is already gone.
  • The accessible name can include words from a label, including words you did not notice. Read the suggestion in the failure.

Remember

A locator describes a thing by its job and its name, and it looks again every time. Start with getByRole and getByLabel.
