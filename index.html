Programming fundamentals

16 lessons · Open this layer

This layer teaches what a program is, before any tool or library. You will meet instructions, code, languages, JavaScript, Node.js, and the pieces every later script is built from: values, lists, records, decisions, repetition, functions, and errors.

Read these sixteen lessons in order. Each one uses only ideas from the lessons before it.

  1. 01
    What is a computer program?

    A program is a list of instructions prepared ahead of time.

  2. 02
    What is code?

    Code is the written form of a program, in a strict spelling.

  3. 03
    How does a computer understand instructions?

    A translator turns your text into steps the machine can carry out.

  4. 04
    What is a programming language?

    A language is an agreed set of rules for writing instructions.

  5. 05
    What are JavaScript and Node.js?

    JavaScript is the language. Node.js runs it outside the browser.

  6. 06
    Your first program

    Make a folder, write a file, run it with node.

  7. 07
    Variables

    A variable is a name attached to a value.

  8. 08
    Numbers and text

    Numbers calculate. Text is a string of characters. Quotes make text.

  9. 09
    Arrays

    An array is an ordered list. The first item is index 0.

  10. 10
    Objects

    An object groups named values into one record.

  11. 11
    Conditions

    if, else if, and else choose which instructions run.

  12. 12
    Loops

    A loop repeats instructions for each item, or until a test fails.

  13. 13
    Functions

    A function is a named block you can run whenever you call it.

  14. 14
    Errors

    An error stops the current work and points at a line.

  15. 15
    Debugging

    Debugging is gathering evidence about what the program actually did.

  16. 16
    Putting everything together

    One small program uses names, a list, a function, a branch, and a loop.

JavaScript for practical automation

17 lessons · Open this layer

This layer points the fundamentals at small jobs on your computer: the terminal, npm, arguments, environment variables, files, paths, JSON, text, lists, dates, modules, promises, async, HTTP, and a script that writes a report.

Files that contain import are saved with the .mjs ending so Node.js treats them as modules. Lessons 1 through 5 can stay as ordinary .js files.

  1. 01
    The terminal

    The terminal is where you send short commands to your computer.

  2. 02
    Running JavaScript files with Node.js

    node runs a file. The exit code tells the shell whether it worked.

  3. 03
    npm and package.json

    npm installs packages. package.json lists them.

  4. 04
    Command-line arguments

    process.argv is the list of words you typed after node.

  5. 05
    Environment variables

    The environment is a place for settings, including secrets.

  6. 06
    Reading and writing files

    A script can save text and read it back.

  7. 07
    Paths and folders

    A path is an address. node:path builds one that works on your system.

  8. 08
    JSON

    JSON is a text format for data. Parse it into values. Stringify values into text.

  9. 09
    Cleaning up text

    Real text arrives with spaces, odd case, and separators.

  10. 10
    Transforming lists

    map, filter, and reduce build new arrays from old ones.

  11. 11
    Dates and times

    Date holds an instant. Intl formats it for people.

  12. 12
    Modules

    export shares a function. import uses it from another file.

  13. 13
    Promises

    A promise is a value that will arrive, or fail, later.

  14. 14
    async and await

    await pauses one function until a promise settles.

  15. 15
    HTTP requests with fetch

    fetch asks a server for a response. Check response.ok.

  16. 16
    Logs and exit codes

    Logs are for people. Exit codes are for the shell.

  17. 17
    A script that turns a list into a report

    Read lines, clean them, write a dated report, exit with a code.

Playwright

20 lessons · Open this layer

Playwright lets a Node.js program drive a real browser: open pages, click, type, and check what a person would see. These twenty lessons assume you can read JavaScript, including async and await.

Use a site and an account you are allowed to automate. The examples use https://example.com and pages the test builds itself, so you can learn the tool without touching anyone else’s login.

  1. 01
    What browser automation is

    A program performs the clicks and reads the screen.

  2. 02
    What Playwright is

    Playwright is a library that drives Chromium, Firefox, and WebKit.

  3. 03
    Browser JavaScript, Node.js, and Playwright

    Three places JavaScript shows up, with different powers.

  4. 04
    Installing Playwright

    Create a project, install the test runner, install the browsers.

  5. 05
    The library and the test runner

    playwright launches browsers. @playwright/test organizes checks.

  6. 06
    Your first test

    A test opens a page and expects a title.

  7. 07
    Browser, context, and page

    The browser is the app. A context is a clean profile. A page is a tab.

  8. 08
    Navigating

    goto opens an address. url, title, reload, and goBack read the trip.

  9. 09
    Locators

    Find elements by their role and name, the way a person would.

  10. 10
    Actions

    click, fill, check, and press do what a person would do.

  11. 11
    Auto-waiting

    Actions wait until the element is ready. Fixed sleeps hide bugs.

  12. 12
    Assertions

    expect on a locator retries. expect on a plain value does not.

  13. 13
    Forms

    Locate inputs by their label. fill, check, and select, then assert the result.

  14. 14
    Screenshots, video, and traces

    When a test fails, keep a picture and a recording of the steps.

  15. 15
    Pages and popups

    Wait for the popup before the click that opens it.

  16. 16
    Frames

    A frame is a page inside a page. Locate it, then locate inside it.

  17. 17
    Network routing

    page.route answers a request on behalf of the network.

  18. 18
    Saving a login with storage state

    Log in once, save cookies, reuse the profile.

  19. 19
    Configuration, projects, and hooks

    playwright.config.js sets defaults. beforeEach shares setup. Projects name browsers.

  20. 20
    Debugging a failing test

    Read the call log, open the trace, watch one run, then fix one thing.

How to study

  1. Read the one idea at the top of the lesson.
  2. Press Run in the practice box. Change one thing, and run again.
  3. When the box feels clear, you can save the same program as a file and run it with Node. That step can wait.
  4. Mark the lesson when you can explain it. The mark stays in this browser.

What you need

A browser is enough to start. The practice boxes run in the page. Install Node.js when you want the same programs as files on your computer. Playwright is the third layer, after those boxes make sense.

The pages are plain HTML. Nothing else has to be installed to read them or to use the practice boxes.

Browser JavaScript and Node.js are introduced before Playwright. Stay in order the first time through.

From Zero. Fundamentals, practical JavaScript, then Playwright. Examples use current Node.js and Playwright habits: let and const, ===, node: built-in modules, web-first locators, and async / await.
