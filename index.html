Programming fundamentals

17 lessons · Open this layer

This layer teaches what a program is, before any extra tool. You meet steps, written text, a language, names for values, lists, forms, choices, repeats, recipes, and errors. Each of those words is explained in the lesson that introduces it.

Read these seventeen lessons in order. Each one uses only ideas from the lessons before it. A program appears after the idea is already clear.

  1. 01
    What is a computer program?

    A program is a list of instructions prepared ahead of time.

  2. 02
    What is code?

    Code is the written form of a program, in a strict spelling.

  3. 03
    How does a computer understand instructions?

    A helper reads your file and follows the spelling rules.

  4. 04
    What is a programming language?

    A language is an agreed set of rules for writing instructions.

  5. 05
    What are JavaScript and Node.js?

    JavaScript is the language. Node.js runs it outside the browser.

  6. 06
    Your first program

    Write one line in a file, then ask the computer to run that file.

  7. 07
    Variables

    A variable is a name attached to a value.

  8. 08
    Numbers and text

    Numbers calculate. Text is a string of characters. Quotes make text.

  9. 09
    Operators

    Symbols that add, compare, and answer yes or no.

  10. 10
    Arrays

    A list in order. The first item is number 0.

  11. 11
    Objects

    One form, with a name on each blank.

  12. 12
    Conditions

    A test picks one path. The other paths stay quiet.

  13. 13
    Loops

    The same steps run once for each item in a list.

  14. 14
    Functions

    A named recipe you write once and use with new ingredients.

  15. 15
    Errors

    An alarm points at a line. You can watch for it and answer it.

  16. 16
    Debugging

    Show the value you are unsure about, then change one thing.

  17. 17
    Putting everything together

    One small program keeps a list, chooses a path, and repeats a recipe.

JavaScript for practical automation

17 lessons · Open this layer

This layer uses the fundamentals for small jobs on your computer: the command window, installing helpers, extra words you type, settings, files, addresses, data written as text, lists, dates, sharing recipes between files, waiting for a later answer, asking another computer, and one script that writes a report.

Each lesson explains its words before the program. The practice box runs in the page.

  1. 01
    The terminal

    The terminal is where you send short commands to your computer.

  2. 02
    Running JavaScript files with Node.js

    Type node and a file name. A number at the end says whether it worked.

  3. 03
    npm and package.json

    A helper installs extra tools. A list in the project remembers them.

  4. 04
    Command-line arguments

    The extra words you type after the file name.

  5. 05
    Environment variables

    Settings that live outside the file, such as a password.

  6. 06
    Reading and writing files

    A script can save text and read it back.

  7. 07
    Paths and folders

    A path is the address of a file or a folder.

  8. 08
    JSON

    A strict way to write data as text, and turn that text back into values.

  9. 09
    Cleaning up text

    Real text arrives with spaces, odd case, and separators.

  10. 10
    Transforming lists

    Build a new list from an old one: change each item, keep some, or combine them.

  11. 11
    Dates and times

    A moment in time, and a way to show it to a person.

  12. 12
    Modules

    Put a recipe in one file and use it from another.

  13. 13
    Promises

    A note that says the answer will arrive later.

  14. 14
    async and await

    Pause one recipe until that later answer arrives.

  15. 15
    HTTP requests with fetch

    Ask another computer for information, and check that the answer arrived.

  16. 16
    Logs and exit codes

    Messages are for people. A final number is for the program that started you.

  17. 17
    A script that turns a list into a report

    Read a list, clean it, and write a short report.

Playwright

20 lessons · Open this layer

Playwright lets a program drive a real browser: open pages, click, type, and check what a person would see. These lessons assume you finished the earlier ones. Words such as “wait for this step” are explained again when they show up.

Use a site and an account you are allowed to automate. The examples use example.com and pages the check builds itself, so you can learn the tool without touching anyone else’s login.

  1. 01
    What browser automation is

    A program performs the clicks and reads the screen.

  2. 02
    What Playwright is

    Playwright is the tool that drives Chrome, Firefox, and Safari’s engine.

  3. 03
    Browser JavaScript, Node.js, and Playwright

    The same language can run in a page, on your computer, or as the driver. Those are different rooms.

  4. 04
    Installing Playwright

    Set the tool up when you are ready: a folder, the checker, and the browsers.

  5. 05
    The library and the test runner

    One part drives the browser. Another part organizes the checks.

  6. 06
    Your first test

    A first check: open a page and look at its title.

  7. 07
    Browser, context, and page

    The browser is the app. A context is a clean profile. A page is one tab.

  8. 08
    Navigating

    Open an address, then read where you landed.

  9. 09
    Locators

    Find a button or a heading the way a person would: by its job and its words.

  10. 10
    Actions

    Click, type, and tick boxes, the way a person would.

  11. 11
    Auto-waiting

    The tool waits until the page is ready. A guessed pause hides problems.

  12. 12
    Assertions

    A check aimed at the page keeps looking for a moment. A check of a plain value answers once.

  13. 13
    Forms

    Fill a form using the label a person can see, then check the result.

  14. 14
    Screenshots, video, and traces

    When a check fails, keep a picture and a recording of the steps.

  15. 15
    Pages and popups

    A click sometimes opens a new tab. Wait for that tab.

  16. 16
    Frames

    A page can contain a smaller page. Find the small page, then find things inside it.

  17. 17
    Network routing

    Answer a network request yourself, so a check does not depend on the real server.

  18. 18
    Saving a login with storage state

    Log in once, save that login, and reuse it.

  19. 19
    Configuration, projects, and hooks

    A settings file for the whole suite, a shared setup step, and a name for each browser.

  20. 20
    Debugging a failing test

    When a check fails, read the story of what happened, then change one thing.

How to study

  1. Read the everyday story and the list of new words.
  2. Follow the numbered steps. That part has no program.
  3. Then look at the program. It is the same steps, in the computer’s spelling.
  4. Press Run. Change one thing, and run again.
  5. Mark the lesson when you can explain it without looking at the code. The mark stays in this browser.

What you need

A browser is enough to start. The practice boxes run in the page. Install Node.js when you want the same programs as files on your computer. The browser-driving lessons are the third layer, after those boxes make sense.

The pages are plain HTML. Nothing else has to be installed to read them or to use the practice boxes.

Browser JavaScript and Node.js are introduced before Playwright. Stay in order the first time through.
