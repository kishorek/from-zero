Putting everything together

One idea. A small program keeps a list, chooses a path, and repeats a recipe.

Start with a normal day

A kitchen has one order ticket. The ticket is a list of chores. A plating rule says how one line should look. The cook walks down the ticket.

If the ticket is blank, someone should say “Nothing to do.” Silence looks like a broken kitchen.

Every piece below is one you have already met. The list. The recipe. The choice. The counted repeat.

New words

No brand-new idea. These are reminders, because they appear together.

array
The list, written in square brackets. The first address is 0.
function
The recipe for one line. It hands text back with return. It does not show the line itself.
${ }
Inside backticks, drop a value into the sentence.
if
Choose a path. === asks whether two values are the same.
for
The counted repeat. i starts at 0, keeps going while it is a real address, and then adds 1.
index + 1
People start counting at 1. The address starts at 0. Adding 1 is the translation.

The steps, before any program

  1. Write three chores in a list.
  2. Prepare a recipe that turns one chore, and its address, into a numbered line.
  3. If the list is empty, say “Nothing to do.”
  4. Otherwise, walk the list. For each chore, show the recipe’s line.

The program is those four steps and nothing more. Read them until you can say them without looking.

The same steps, written as a program

Read the four steps once more. Then look. The first line is the list. The recipe comes next. The choice and the repeat come last.

What you should see
1. Buy milk
2. Reply to Ada
3. Water the plant

What each line is saying

  1. const tasks = ["Buy milk", "Reply to Ada", "Water the plant"];The list of chores. This is the data. The rest of the file is the rules.
  2. function formatTask(task, index) {The recipe for one line. It waits for a chore and an address. It does not show anything yet.
  3. return `${index + 1}. ${task}`;Hand back a numbered line. Address 0 becomes the number 1 that a person expects.
  4. if (tasks.length === 0) {Ask whether the list is empty. Three equals signs ask. They do not store.
  5. for (let i = 0; i < tasks.length; i = i + 1) {Count 0, then 1, then 2. Stop when the count is no longer a real address.
  6. console.log(formatTask(tasks[i], i));Take the chore at this address, hand it to the recipe with that address, and show the line that comes back.

Try it

Press Run. You should see four chores, with Buy milk first. Then set tasks to [] and run again. You should see Nothing to do.

Practice. The recipe builds one line. The repeat asks for each chore.

Easy to mix up

  • Give the numbering one home. If both the recipe and the repeat add a number, the number shows up twice.
  • Showing i by itself starts the list at 0. Add 1 when a person will read it.
  • An empty list makes the repeat show nothing. The empty check is what says “Nothing to do.”

Remember

You can store a list, shape one line with a recipe, choose a path when the list is empty, and repeat through the rest. That is a whole small program.
