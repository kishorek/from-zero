Arrays

One idea. An array is a list in order. The first item is number 0.

Start with a normal day

Picture a row of mailboxes. The first box, the one by the door, is numbered 0. The next is 1. The one after that is 2.

Three boxes are numbered 0, 1, and 2. Asking for box 3 finds an empty slot. There is no fourth box yet.

You can add a box at the end of the row. The count of boxes goes up by one.

New words

The list in this lesson is three tea steps.

array
A list of values kept in order.
[ ]
Square brackets. They wrap the list. Commas separate the items.
index
The number address of one item. The first index is 0. The second is 1.
length
How many items are in the list. Three items means length is 3. The last index is then 2.
push
Add one item at the end of the list.
const
The name steps stays on this same list. You may still change what is inside the list.

The steps, before any program

  1. Write a list of three words: boil, steep, pour.
  2. Show the first word. Its address is 0.
  3. Show how many words are in the list.
  4. Add the word sip at the end, and show the whole list.

The program writes that list with square brackets.

The same steps, written as a program

Read the four steps again. steps[0] means “the item at address 0.” The first item is boil.

What you should see
boil
3
[ 'boil', 'steep', 'pour', 'sip' ]

What each line is saying

  1. const steps = ["boil", "steep", "pour"];Store a list of three pieces of text. Commas separate them. The name steps stays on this list.
  2. console.log(steps[0]);Show the item at address 0. That is the first item, boil.
  3. console.log(steps.length);Show how many items there are. There are 3, even though the last address is 2.
  4. steps.push("sip");Add sip at the end. The name steps still points at the same list. The inside of the list changed.
  5. console.log(steps);Show the whole list. It now has four words.

Try it

The box shows the first breakfast, the last one, and the count. Then it adds fruit. The last number should be 4. The last item’s address is length minus 1.

Practice. Address 0 is the first item. The last address is length minus 1.

Easy to mix up

  • Address 0 is the first item. Starting at 1 skips it.
  • length counts items. The last address is length - 1.
  • Items in a list need commas between them. A missing comma stops the program, and the message points at that line.

Remember

An array is an ordered list in square brackets. Indexes begin at 0. length counts the items. push adds one at the end.
