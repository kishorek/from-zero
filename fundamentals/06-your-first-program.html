Your first program

One idea. A first program is one file and one command: node, then the file name.

The idea

A JavaScript file is a plain text file whose name ends in .js. Node.js runs that file when you type node, a space, and the file name.

The terminal is the window where you type those commands. On macOS it is Terminal. The folder you are “in” matters, because Node.js looks for the file there.

Why it matters

From here on, every example is something you run. Reading code and running code are different skills. Running shows you what the engine actually did.

A picture to hold

The file is a recipe card. node hello.js is you handing that card to the cook. The terminal is the pass where the cook sends plates back, one printed line at a time.

A small example

In the terminal, create a folder, enter it, and create the file in your editor. Then run it from that folder.

What you should see
Hello, I am your first program.

Line by line

  1. mkdir from-zero-labmkdir means make directory. A directory is a folder. This creates a new folder in the place you currently are.
  2. cd from-zero-labcd means change directory. After this, commands look inside that folder.
  3. console.log("Hello, I am your first program.");The whole program. One instruction. Node.js prints the text and then finishes.
  4. node hello.jsStarts Node.js and tells it which file to read. You type this in the terminal, not inside the JavaScript file.

Try it yourself

Print your name on one line and your city on the next. Two console.log lines are enough.

Practice. Replace the sample name and city with yours.

Common mistakes

  • Typing console.log into the terminal by itself. The terminal runs commands such as node. The JavaScript goes in the file.
  • Saving the file as hello.js.txt. Turn on file extensions in your editor and confirm the name ends in .js.
  • Running node hello.js from a different folder than the file. cd into the folder first.

Recap

Write JavaScript in a .js file. From that file’s folder, run node and the file name. The terminal shows what the program prints.
