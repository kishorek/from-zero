Your first program

One idea. Write one line in a file. Then type node and the file name.

Start with a normal day

A recipe card sits on the counter. Handing the card to the cook is a separate action from writing the card.

The file is the card. The terminal is the window where you type short commands. On a Mac, that window is called Terminal.

You type node, a space, and the file name. Node.js reads the file and sends back what the program prints.

New words

The commands come first as words. The program is one line you already know.

file
A saved text document. A JavaScript file’s name ends in .js.
terminal
The window where you type commands to your computer.
folder
A place that holds files. People also say directory.
mkdir
The command “make a folder.” You type it in the terminal.
cd
The command “go into this folder.” After it, the next commands look in that folder.
node
The command that starts Node.js and names the file to run. You type it in the terminal, not inside the file.
console.log
Inside the file, the spelling for “show this on the screen.”

The steps, before any program

  1. Make a folder named from-zero-lab.
  2. Go into that folder.
  3. In your editor, save a file there named hello.js, with one line that shows a greeting.
  4. In the terminal, type node hello.js.

The practice box on this page only does the greeting. The folder commands are for when you install Node.js.

The same steps, written as a program

Read the four steps again. The first box is what you type in the terminal. The second box is the whole file. One line. One greeting.

What you should see
Hello, I am your first program.

What each line is saying

  1. mkdir from-zero-labMake a new folder in the place you are now. You type this in the terminal.
  2. cd from-zero-labGo into that folder. Node.js will look for the file there.
  3. console.log("Hello, I am your first program.");This line lives in the file. It shows the greeting. The semicolon ends the step.
  4. node hello.jsStart Node.js and hand it the file. You type this in the terminal, after you are inside the folder.

Try it

The box has a name and a city. Change both to yours. Press Run. You should see two lines.

Practice. Two lines. Your name, then your city.

Easy to mix up

  • console.log belongs in the file. node belongs in the terminal.
  • The file name ends in .js. A name like hello.js.txt is a different file.
  • Type cd into the folder before node hello.js. Node.js looks in the folder you are in.

Remember

Write the steps in a .js file. From that file’s folder, type node and the file name. The terminal shows what the program prints.
