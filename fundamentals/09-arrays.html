Arrays

One idea. An array is an ordered list. The first item is index 0.

The idea

An array holds values in order. You write it with square brackets: ["boil", "steep", "pour"]. Each item has an index, a number address. The first index is 0, not 1. The second is 1.

length tells you how many items are in the array. push adds an item at the end.

Why it matters

Real jobs come in lists: files in a folder, rows in a report, links on a page. An array is how JavaScript holds a list so you can walk it later with a loop.

A picture to hold

A row of mailboxes numbered from 0. Mailbox 0 is the first box, the one closest to the door. Asking for mailbox 3 in a row of three boxes (0, 1, and 2) does not find a fourth box. It finds nothing.

A small example

What you should see
boil
3
[ 'boil', 'steep', 'pour', 'sip' ]

Line by line

  1. const steps = ["boil", "steep", "pour"];Create an array of three strings. Commas separate items.
  2. console.log(steps[0]);Square brackets after the name read one item. Index 0 is the first item, boil.
  3. console.log(steps.length);length is 3. There are three items, even though the last index is 2.
  4. steps.push("sip");push adds sip at the end. const blocks replacing steps itself. It does not block changing the contents of the array.
  5. console.log(steps);Print the whole array. Node.js shows it in brackets.

Try it yourself

Print the first breakfast, the last one, and the length. Then push one more item and print the length again. The last number should be 4.

Practice. The last index is length - 1.

Common mistakes

  • Starting at index 1 and skipping the first item.
  • Using length as if it were the last index. The last index is length - 1.
  • Writing a list without commas between the items. The engine will stop at the syntax error.

Recap

An array is an ordered list in square brackets. Indexes begin at 0. length counts items. push adds to the end.
