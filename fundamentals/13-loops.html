Layer 01 · Lesson 13 of 17

Loops

One idea. A loop repeats one group of steps, once for each item in a list.

Start with a normal day

You have a rubber stamp and a stack of envelopes. The stamp is the step. The stack is the list.

You stamp the first envelope, then the next, until the stack is empty. You do not carve a new stamp for each envelope.

Sometimes you also want the envelope’s number. Then you count as you go: 0, then 1, then 2. People often show that count plus 1, so the first line says 1.

New words

The program stamps three tea steps. The practice box numbers three names.

loop
A group of steps that runs again until the list, or the test, is finished.
for...of
for (const step of steps) means “for each item in this list, call it step, and run the steps in the braces.”
counted for
for (let i = 0; i < steps.length; i = i + 1). i starts at 0. The middle test keeps going while i is still a real address. The last part adds 1.
i
A common name for the counter. It is an index, so it starts at 0.
{ }
The braces hold the steps that repeat.
while
Another loop that repeats while a test stays true. If the test never becomes false, it runs until you stop it. In a terminal, Ctrl+C stops it. This page’s program uses for.

The steps, before any program

  1. Write the list: boil, steep, pour.
  2. Take the first word. Show “Now:” and that word.
  3. Take the next word and do the same thing.
  4. Stop when the list is finished.

You write the “show Now” step once. The loop supplies the next word.

The same steps, written as a program

Read the four steps again. The line that starts with for is “take each word.” The line inside the braces is the stamp.

What you should see
Now: boil
Now: steep
Now: pour

The practice box needs the number as well as the name, so it uses the counted loop from the word list. i + 1 turns the address 0 into the number 1 that people expect.

What each line is saying

  1. const steps = ["boil", "steep", "pour"];The list to walk.
  2. for (const step of steps) {Take each item. The first time, step is boil. Then steep. Then pour.
  3. console.log("Now: " + step);This line runs once per item. The plus sign glues the label and the current word.
  4. }The closing brace ends the repeated steps. After the last item, the program continues underneath. In this file, that is the end.

Try it

Press Run. You should see three names, numbered from 1. Ada is first, so the first line starts with 1.

Practice. The counter starts at 0. Add 1 when you show it to a person.

Easy to mix up

  • for (const step of steps) wants the list. steps.length is only a number, so it cannot be the list you walk.
  • In a counted loop, i = i + 1 moves you forward. Leave it out, and the loop never reaches the end.
  • Adding items with push to the same list you are walking can make the walk grow forever. Build a new list, or walk a copy.

Remember

for...of repeats once per item. A counted for also gives you the address. Each pass has to move toward the end.
