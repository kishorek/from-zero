Loops

One idea. A loop repeats one block for each item in a list.

The idea

A loop repeats a block. for...of walks an array from first item to last and gives you each item under a name. A counted for is useful when you also need the index.

The block must make progress. A while that never becomes false runs until you stop the program. In the terminal, Ctrl+C stops it.

Why it matters

Doing the same work for every file, every row, or every link is the heart of automation. You write the step once. The loop supplies the next item.

A picture to hold

A rubber stamp and a stack of envelopes. The stamp is the block. The stack is the array. for...of picks up the next envelope until the stack is empty. You do not rewrite the stamp for each envelope.

A small example

What you should see
Now: boil
Now: steep
Now: pour

When you need the index too, use a counted loop: for (let i = 0; i < steps.length; i = i + 1). i starts at 0. The middle test keeps going while i is still a valid index. The last part moves i forward by one.

Line by line

  1. const steps = ["boil", "steep", "pour"];The list to walk.
  2. for (const step of steps) {of means “each item in this array.” The first time through, step is boil. Then steep. Then pour.
  3. console.log("Now: " + step);This line runs once per item. Plus joins the label and the current item.
  4. }The closing brace ends the repeated block. After the last item, the program continues under the loop. In this file, that is the end.

Try it yourself

Print three names numbered from 1. The first line should start with 1.

Practice. People count from 1. The index starts at 0, so add 1 when you print.

Common mistakes

  • Writing for (const step of steps.length). of wants the array, not the number of items.
  • Forgetting to move i forward in a counted loop, which makes an infinite loop. The i = i + 1 part is the step.
  • Changing the array with push inside a for...of that walks that same array. You can grow the walk forever. Build a new array, or loop a copy.

Recap

for...of repeats a block once per item. A counted for also gives you the index. Each pass must move toward the end.
