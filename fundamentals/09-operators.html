Operators

One idea. An operator is a symbol that does a job with values.

Start with a normal day

A calculator adds. A form asks a yes-or-no question. Both are symbols sitting between two values.

You have 10 apples. Add 2. Then ask how many are left over if 3 people share them. Then ask whether you still have at least 5.

New words

Learn these symbols before the program. The chart further down adds a few more.

operator
A symbol that takes values and produces a result.
+
Adds two numbers. On text, it glues.
%
The remainder. 10 % 3 is 1, because 3 fits into 10 three times and 1 is left.
>=
Asks “is the first value at least as big as the second?” The answer is true or false.
===
Asks “are these the same value, and the same kind?” One equals sign stores. Three equals signs ask.
!==
Asks “are these different?”
&&
Both answers must be true. Like two light switches in a row.
true and false
The only two answers a yes-or-no question can give.
=
One equals sign stores a value under a name.

The steps, before any program

  1. Remember that there are 10 apples.
  2. Show 10 plus 2.
  3. Show the remainder when 10 is shared by 3.
  4. Show whether 10 is at least 5.

Three questions. The program writes them with three symbols.

The same steps, written as a program

Read the four steps again. The first line only remembers the 10. Each console.log line is one question.

What you should see
12
1
true

What each line is saying

  1. const apples = 10;Store the number 10 under the name apples.
  2. console.log(apples + 2);Show 10 plus 2. The result is 12.
  3. console.log(apples % 3);Show what is left when 3 people share 10 apples. The result is 1.
  4. console.log(apples >= 5);Ask whether 10 is at least 5. The answer is true.

A few more symbols

You do not need these for the program above. The practice box uses “both” and “different.” The others can wait until you meet them.

SymbolWhat it does
- * /Subtract, multiply, and divide. The star is the multiply sign.
> < <=Greater than, less than, and “at most.”
||Either answer may be true. Like two switches side by side.
!Flips an answer. True becomes false. False becomes true.

Try it

7 cookies are shared by 3 friends. The first line shows the remainder, which is 1. The second line asks two questions that are both true, so you should see true.

Practice. First the leftover cookies. Then “are there cookies, and is there a friend?”

Easy to mix up

  • One equals sign stores a value. Three equals signs ask whether two values are the same.
  • "10" + 2 glues text and produces "102". The quotes make the 10 into text.
  • && produces true or false. It does not print the word “and”.

Remember

+ and % calculate. >= and === answer yes or no. && asks for both answers to be true. One equals sign stores.
