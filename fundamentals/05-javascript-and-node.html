What are JavaScript and Node.js?

The idea

JavaScript is a programming language. It was first built for web pages. A browser still runs JavaScript inside a page. That kind of JavaScript can change what you see, and it is kept away from your files for safety.

Node.js is a program you install. It runs JavaScript on your computer, outside any page. Node.js can read files, talk on the network, and start other programs. It cannot see a web page by itself. Playwright, much later, is the tool that lets a Node.js program drive a browser.

Install the Long Term Support release from https://nodejs.org. Then open a terminal and run node -v. You want version 20 or newer. Playwright requires that. npm -v should also print a number. npm is the installer for JavaScript packages, and it arrives with Node.js.

Why it matters

Mixing these up causes a specific kind of confusion: copying browser code into Node, or Node code into a page, and watching it fail. The example shows a clean test. In Node, document is not there, because document means “the page.”

A picture to hold

JavaScript is a written language. The browser is a reading room with one window onto a page. Node.js is a workshop with doors onto your files and the network, and no window onto a page. Same language, different rooms.

Where it runsInside a web pageOn your computer, in the terminal

Can it click a website for you?Only as the page’s own scriptNot alone. Playwright does that later

A small example

What you should see
Running with Node v22.x.x
undefined

Your version number will differ. undefined here means “there is no document in this room.” In a browser console, typeof document is "object".

Line by line

  1. console.log("Running with Node " + process.version);process is a Node.js object that describes the running program. process.version is the Node.js version text.
  2. console.log(typeof document);typeof asks what kind of thing a name points at. document was never created in Node.js, so the answer is undefined.

Try it yourself

Install Node.js if you have not. Run node -v and npm -v. Then run where.js. In the last line of the file, replace document with process and run it again. typeof process prints object, because Node.js did create that name.

Common mistakes

  • Opening a .js file by double-clicking it and expecting Node.js to run. Use the terminal: node where.js.
  • Pasting document.querySelector into a Node.js file. That name belongs to the browser.
  • Installing an old Node.js. This course, and current Playwright, want Node.js 20 or newer.

Recap

JavaScript is the language. Browsers run it inside a page. Node.js runs it in a workshop on your computer. document belongs to the page. process belongs to Node.js.
