What are JavaScript and Node.js?

One idea. JavaScript is the language. Node.js is a program that runs that language on your computer.

Start with a normal day

English can be spoken in a library or in a workshop. The language is the same. The room changes what you are allowed to touch.

JavaScript started inside web pages. A browser still runs it there. In that room it can change the page you see. It is kept away from your files.

Node.js is a program you can install. It runs the same language in a workshop on your computer. That workshop can read files. It has no web page of its own.

New words

The practice box pretends to be the Node.js workshop. These words name the two rooms.

JavaScript
The spelling rules this course uses.
browser
The program that shows web pages. It can run JavaScript inside one page.
Node.js
A program that runs JavaScript on your computer, outside any page. The command you type is node.
document
A name that means “this web page.” It exists in the browser. It is missing in Node.js.
process
A name that means “this running Node.js program.” It exists in Node.js. It is missing in an ordinary page.
typeof
A question: what kind of thing is this name? If the name is missing, the answer is undefined.
undefined
The answer you get when a name was never created in this room.
console.log
The spelling for “show this on the screen.”

The steps, before any program

  1. Ask what kind of thing document is. In the Node.js room, that name was never created.
  2. Ask what kind of thing process is. In the Node.js room, that name exists.

Easy to mix up

  • JavaScript is the language. Node.js is one program that runs that language. A browser is a different program that runs it too.
  • Double-clicking a .js file does not start Node.js. The command is node, then the file name. The next lesson walks through that.
  • document belongs to a web page. Pasting it into a Node.js file asks for a name that room does not have.

Remember

JavaScript is the language. The browser runs it inside a page. Node.js runs it on your computer. document belongs to the page. process belongs to Node.js.
