What is a programming language?

The idea

A programming language is a set of rules for writing instructions so a translator can accept them. JavaScript is one language. Python is another. The processor does not prefer either. The tools you install do.

Languages differ in vocabulary and punctuation. They can still express the same job: remember a name, repeat a step, stop when a condition is met. You are learning JavaScript because Node.js and Playwright speak it.

Why it matters

When a later lesson says “this is JavaScript, and it runs in Node,” you will know that the language and the tool are two things. The language is the rules. Node.js is a program that carries out JavaScript on your computer.

A picture to hold

French and Japanese can both tell a cook to simmer a soup. The cook needs someone who knows the language you chose. JavaScript and Python can both describe the same task. Node.js is a listener for JavaScript.

A small example

What you should see
This file is written in JavaScript.

Line by line

  1. const language = "JavaScript";const creates a name, language, and stores the text JavaScript under that name. Lesson 7 spends a whole page on this.
  2. console.log("This file is written in " + language + ".");Plus joins three pieces: text, the stored name, and a period. The engine looks up language and uses the text stored there.

Try it yourself

Change the stored text to "Python" and run the file again. The sentence changes, and the file is still a JavaScript program. The word inside the quotes is data. The rules around it are the language.

Common mistakes

  • Treating the programming language and the application as the same thing. JavaScript is the language. Node.js, Chrome, and Playwright are programs that use it.
  • Expecting Python spelling to work in a JavaScript file. Each language has its own rules.
  • Thinking a language is only for websites, or only for math. A language can describe many jobs. The tools decide which jobs are easy.

Recap

A programming language is a shared rulebook for instructions. JavaScript is the rulebook in this course. Node.js is one program that follows that rulebook.
