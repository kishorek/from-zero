What is a programming language?

One idea. A programming language is a shared set of spelling rules.

Start with a normal day

French and Japanese can both ask a cook to simmer a soup. The cook needs someone who knows the language you chose.

JavaScript and Python can both describe the same job. The spelling changes. The job can stay the same.

This course uses JavaScript. The helper that runs these pages knows that spelling.

New words

Two names, and the marks in the one-line program.

programming language
An agreed set of rules for writing steps so a helper can follow them.
JavaScript
The language used in this course.
Python
A different language, with different spelling, that can describe many of the same jobs.
console.log
JavaScript spelling for “show this on the screen.”
quotes
The marks " around text.
semicolon
The mark ; that ends a step.

The steps, before any program

  1. Decide to show one sentence.
  2. Write that sentence with JavaScript’s spelling rules.

The sentence mentions another language. The file itself still follows JavaScript’s rules.

The same steps, written as a program

There is one step: show a sentence. The words inside the quotes are the sentence. The words outside the quotes are JavaScript’s spelling.

What you should see
This file follows JavaScript rules.

What each line is saying

  1. console.log("This file follows JavaScript rules.");Show the sentence between the quotes. console.log is JavaScript’s way to ask for that. A different language would use a different word for the same job.

Try it

Press Run. The second line mentions Python. The spelling around it is still JavaScript, so the box can run it. You should see both lines.

Practice. The words in quotes are the sentence. The spelling around them is JavaScript.

Easy to mix up

  • JavaScript is the set of spelling rules. A browser, and the tool that runs a file, are programs that follow those rules.
  • Python spelling stays in a Python file. This course’s files follow JavaScript spelling.
  • A language can describe many jobs. The tools you install decide which jobs are easy.

Remember

A programming language is a shared rulebook. JavaScript is the rulebook in this course. The same job can be written in another rulebook, with different spelling.
