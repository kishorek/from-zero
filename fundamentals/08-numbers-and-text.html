Numbers and text

One idea. Numbers calculate. Quoted text is glued together.

The idea

A number is for arithmetic: 4.5, 2, -1. Text is called a string, because it is a string of characters. You write a string between quotes: "tea" or 'tea'.

A template literal is a string written with backticks. Inside it, ${price} is replaced with the value of price. You will see that spelling in the example as a sentence that includes the item and the price.

typeof reports the kind of value. Numbers report "number". Strings report "string".

Why it matters

Files, web pages, and test names are mostly text. Prices, counts, and status codes are numbers. Keeping them apart prevents the "10" + 2 surprise, which glues text and produces "102".

A picture to hold

A number is a weight on a scale. You can add weights. A string is a bead necklace. Adding necklaces clasps them into one longer necklace. It does not add the number of beads unless you ask a different question, such as .length.

A small example

What you should see
tea costs 4.5
number
string

Line by line

  1. const price = 4.5;Store a number. No quotes. The decimal point is allowed.
  2. const item = "tea";Store a string. The quotes are boundaries. They are not part of the text.
  3. const line = `${item} costs ${price}`;Backticks build one string. ${item} and ${price} drop the current values into the sentence.
  4. console.log(typeof price);typeof returns the string "number" for a number.
  5. console.log(typeof item);typeof returns the string "string" for text.

Try it yourself

Run both lines. The first prints 102. The second prints 12.

Practice. Number("10") turns text into a number before the addition.

Common mistakes

  • Putting quotes around a number you mean to add. "4.5" is text.
  • Mixing up template punctuation. The insert is ${name} with a dollar sign and braces, inside backticks.
  • Assuming numbers with a leading zero, or numbers written as 04, are always the decimal you expect. Write normal decimals such as 4 and 4.5.

Recap

Numbers do arithmetic. The next lesson names the symbols that do that arithmetic. Strings are quoted text. Template literals build a sentence and insert values with ${}. typeof tells you which kind you have.
