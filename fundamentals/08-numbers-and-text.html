Numbers and text

One idea. A number can be added. Text inside quotes gets glued together.

Start with a normal day

A price tag says 4.50. You can add another price to it. The word “tea” on the same tag is a label. Adding labels sticks them into a longer label.

The sentence you want is “tea costs 4.5”. You already have the word tea, and you already have the number 4.5. The program builds that sentence for you.

New words

The program uses a number, a piece of text, and a sentence that includes both.

number
A value for arithmetic, written with no quotes. 4.5, 2, and -1 are numbers.
string
The programming word for text. It is a string of characters, written inside quotes: "tea".
quotes
The marks around text. Straight quotes " or ' both work. The quotes themselves are not part of the text.
backticks
The slanted quotes `. A string written with backticks can drop values into a sentence.
${ }
Inside backticks, a dollar sign and braces drop in the current value of a name. ${price} becomes 4.5.
typeof
Asks what kind of value this is. A number answers "number". Text answers "string".
Number
Turns text that looks like a number into a real number. Number("10") is the number 10. The practice box uses this.
const
A name you will keep on this value.
+
Adds numbers. Glues text. "10" + 2 glues, and the result is the text "102".

The steps, before any program

  1. Store the price 4.5 as a number. No quotes.
  2. Store the word tea as text. Use quotes.
  3. Build one sentence that includes both.
  4. Ask what kind of thing the price is, and what kind of thing the item is.

The program writes those four steps. The sentence uses backticks so the stored values can drop in.

The same steps, written as a program

Read the four steps again. The strange line is the sentence. The backticks and the ${ } marks are only there to drop the stored values in.

What you should see
tea costs 4.5
number
string

What each line is saying

  1. const price = 4.5;Store a number under the name price. There are no quotes. A decimal point is allowed.
  2. const item = "tea";Store text under the name item. The quotes mark the text. They are not part of the word tea.
  3. const line = `${item} costs ${price}`;Build one sentence. The backticks allow the drop-in marks. ${item} becomes tea. ${price} becomes 4.5.
  4. console.log(typeof price);Ask what kind of value price is, and show the answer. The answer is the word number.
  5. console.log(typeof item);Ask what kind of value item is. The answer is the word string.

Try it

The first line glues the text “10” to the number 2, so you see 102. The second line turns “10” into a number first, then adds, so you see 12. Press Run.

Practice. Quotes make text. Number("10") turns that text into a number.

Easy to mix up

  • "4.5" is text, because of the quotes. 4.5 is a number.
  • The drop-in mark is ${name}, with a dollar sign and braces, and it belongs inside backticks.
  • Write ordinary numbers such as 4 and 4.5. A leading zero, as in 04, is a different spelling with a surprising meaning.

Remember

Numbers do arithmetic. Strings are text inside quotes. Backticks build a sentence and drop values in with ${ }. typeof tells you which kind you have.
