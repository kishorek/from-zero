Functions

One idea. A function is a named block you can run with different inputs.

The idea

A function packages instructions under a name. You define it once. You call it whenever you need that work, possibly with different inputs.

Inputs are parameters, the names in the parentheses. A call passes arguments, the actual values. return sends a value back to the caller and ends the function.

An arrow function is another spelling of the same idea: const labelFor = (item, price) => item + " " + price. It is still a function. This course mentions it now so later pages are readable.

Why it matters

Copying the same lines five times makes five places to fix. A function makes one place. You will reuse functions whenever a job repeats.

A picture to hold

A function is a custom rubber stamp you carve yourself. The parameters are the blank spaces on the stamp. Each call inks the stamp with different words and presses it. return is the paper you hand back.

A small example

What you should see
tea costs 4.5
milk costs 2

Line by line

  1. function labelFor(item, price) {Define a function named labelFor. It expects two values, stored as item and price for this call. Defining it does not run it yet.
  2. return `${item} costs ${price}`;Build a string and hand it back to whoever called the function. Lines after return in the same function would not run.
  3. console.log(labelFor("tea", 4.5));Call the function. "tea" becomes item. 4.5 becomes price. console.log prints whatever the function returns.
  4. console.log(labelFor("milk", 2));A second call with different arguments. The same definition does new work.

Try it yourself

Finish initials so Ada and Lovelace print A.L. Then try your own names.

Practice. first[0] is the first character of a string.

Common mistakes

  • Forgetting to call the function. A definition alone prints nothing.
  • Forgetting return and then wondering why the caller got undefined. If you want a value out, return it.
  • Mixing up the order of arguments. labelFor(4.5, "tea") stores the number in item and the text in price. The names do not reorder your values.

Recap

A function is a named block with inputs and an optional return. A call runs it. Arrow functions are the same idea with a shorter spelling.
