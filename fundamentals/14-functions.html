Functions

One idea. A function is a named recipe. You write it once and use it with new ingredients.

Start with a normal day

You carve one rubber stamp with blank spaces. Each time you use it, you fill the blanks with different words and press it.

The stamp for a price label needs two blanks: the item, and the price. Tea and 4.5 make one label. Milk and 2 make another. The stamp stays the same.

Writing the recipe does not press the stamp. You press it when you ask for it by name.

New words

The recipe is called labelFor. The practice box uses a smaller recipe called initials.

function
A named group of steps you can run whenever you ask for it.
parameter
A blank name in the parentheses, such as item and price. It waits for a value.
argument
The actual value you pass in when you use the function, such as "tea" and 4.5.
call
Using the function by writing its name and parentheses. That is when the steps run.
return
Hand a value back to the caller, and stop the function there.
${ }
Inside backticks, drop a stored value into a sentence. ${item} becomes tea.
[0]
The first character of a piece of text. The practice box uses first[0] to get the first letter. Addresses start at 0.

The steps, before any program

  1. Write a recipe named labelFor. It needs an item and a price.
  2. The recipe hands back one sentence: the item, the word costs, and the price.
  3. Ask for that recipe with tea and 4.5. Show what comes back.
  4. Ask again with milk and 2. Show what comes back.

The recipe is written once. The two calls supply different ingredients.

The same steps, written as a program

Read the four steps again. The first two lines are the recipe. They do not show anything by themselves. The console.log lines are the two times you press the stamp.

What you should see
tea costs 4.5
milk costs 2

What each line is saying

  1. function labelFor(item, price) {Start a recipe named labelFor. It expects two values, stored as item and price for this use. Writing this line does not run the recipe yet.
  2. return `${item} costs ${price}`;Build a sentence and hand it back. The drop-in marks place the current item and price into the sentence.
  3. console.log(labelFor("tea", 4.5));Run the recipe. tea goes into item. 4.5 goes into price. Show the sentence that comes back.
  4. console.log(labelFor("milk", 2));Run the same recipe again, with different values.

Try it

The box builds initials from Ada and Lovelace. The first letter of each name, with a period between them, is A.L. Press Run. You should see A.L.

Practice. first[0] is the first letter. Addresses start at 0.

Easy to mix up

  • Writing the recipe does not run it. A call, the name plus parentheses, runs it.
  • Leave out return, and the caller receives undefined. Hand the value back when you want it out.
  • Order matters. labelFor(4.5, "tea") stores the number in item and the text in price. The names do not sort your values.

Remember

A function is a named recipe with blanks. A call fills the blanks and runs it. return hands a value back.
