Objects

One idea. An object is a record of named facts about one thing.

The idea

An object groups values under names. You write it with curly braces. Each entry is a property: a name, a colon, and a value.

You read a property with a dot: cup.kind. You change a property by assigning to it. This is how one “thing” in your program carries several facts at once.

Why it matters

A test result, a file’s details, and a person’s record are all objects in practice. Arrays are for “many in a row.” Objects are for “several facts about one thing.”

A picture to hold

A paper form with labeled blanks. kind is a blank. mug is what someone wrote in it. An array is a numbered queue. An object is the form each person in that queue might hold.

A small example

What you should see
mug
true

Line by line

  1. kind: "mug",A property. The name is kind. The value is the string mug. Commas separate properties.
  2. volumeMl: 300,A number property. No quotes around the value.
  3. empty: false,false is a boolean, a value that is only true or false. It is not the string "false".
  4. console.log(cup.kind);The dot reads the kind property. This prints mug.
  5. cup.empty = true;Replace the empty property. The name cup still points at the same object. const allows this.

Try it yourself

Print the title, change the pages, and print a missing author. The last line is undefined.

Practice. A missing name prints undefined. It does not crash by itself.

Common mistakes

  • Using a dot for an array index, or brackets-with-a-number for a property you meant to name. steps[0] is an index. cup.kind is a property.
  • Forgetting commas between properties.
  • Writing cup.empty = "false" when you wanted the boolean. The string "false" is still text, and it counts as present.

Recap

An object is a record of named properties inside curly braces. Read them with a dot. A missing property is undefined.
