Objects

One idea. An object is one form, with a name on each blank.

Start with a normal day

An array is a numbered row. An object is a paper form about one thing.

The form for a cup has blanks: what kind it is, how many millilitres it holds, and whether it is empty. Each blank has a label.

You read a blank by its label. You can erase one blank and write a new answer. The form is still the same form.

New words

The form below is one cup.

object
A group of named facts about one thing.
{ }
Curly braces. They wrap the form.
property
One blank on the form: a name, a colon, and a value. Commas separate the blanks.
dot
cup.kind reads the blank named kind. The dot means “the fact called…”
true and false
Yes-or-no values. People call this kind a boolean. false is a value. The text "false" is just text.
undefined
The answer when you ask for a blank the form does not have. The practice box asks for a missing author.
const
The name cup stays on this form. You may still change a blank inside the form.

The steps, before any program

  1. Fill in a form for one cup: kind mug, volume 300, empty no.
  2. Read the kind blank and show it.
  3. Change the empty blank to yes, and show it.

The program writes that form with curly braces and reads a blank with a dot.

The same steps, written as a program

Read the three steps again. Each line inside the braces is one blank. cup.kind is “look at the kind blank.”

What you should see
mug
true

What each line is saying

  1. kind: "mug",One blank. The label is kind. The value is the text mug. The comma separates it from the next blank.
  2. volumeMl: 300,A number blank. No quotes around 300.
  3. empty: false,A yes-or-no blank. false means no. It is a value, not the text “false”.
  4. console.log(cup.kind);Read the kind blank and show it. The screen shows mug.
  5. cup.empty = true;Write yes into the empty blank. The name cup still points at the same form.

Try it

The box shows a book’s title, changes the page count, then asks for an author. There is no author blank, so the last line is undefined.

Practice. title and pages are blanks. author was never filled in.

Easy to mix up

  • steps[0] uses a number address on a list. cup.kind uses a name on a form.
  • Blanks inside the braces need commas between them.
  • false is a yes-or-no value. "false" is text, and it still counts as filled in.

Remember

An object is a form of named blanks inside curly braces. A dot reads a blank. A missing blank is undefined.
