Putting everything together

The idea

The pieces from this layer combine. A real program is rarely one idea at a time. It stores values, keeps them in a list or a record, decides, repeats, and calls functions.

The program below turns a list of tasks into numbered lines. If the list is empty, it says so instead of printing nothing and leaving you unsure.

Why it matters

Layer 2 starts from this shape and aims it at files, JSON, and the network. If you can read this program aloud and say what each part is for, you are ready.

A picture to hold

A kitchen during one meal. The list is the order ticket. The function is the plating rule. The branch is “if there are no orders, tell the front.” The loop is the cook working down the ticket.

A small example

What you should see
1. Buy milk
2. Reply to Ada
3. Water the plant

Line by line

  1. const tasks = ["Buy milk", "Reply to Ada", "Water the plant"];An array of strings. This is the data. The rest of the file is the rules.
  2. function formatTask(task, index) {A function that knows how one line should look. It does not print. It returns text.
  3. return `${index + 1}. ${task}`;Indexes start at 0, and people start at 1. Adding 1 is the translation between those two habits.
  4. if (tasks.length === 0) {A condition. === compares the length to the number 0.
  5. for (let i = 0; i < tasks.length; i = i + 1) {A counted loop. i is 0, then 1, then 2. The test i < tasks.length stops it at the end.
  6. console.log(formatTask(tasks[i], i));Take the item at index i, hand it to the function with that index, and print the returned line.

Try it yourself

Add a fourth task and run the program. Then set tasks to an empty array [] and run it again. You should see Nothing to do.. Finally, change formatTask so the line looks like Buy milk (1) and confirm every line follows.

Common mistakes

  • Doing the formatting inside the loop and also inside the function, so the number appears twice. Give each job one home.
  • Printing i to humans without adding 1, so the list appears to start at 0.
  • Skipping the empty check. An empty loop prints nothing, and nothing looks like a broken program.

Recap

You can store a list, format one item with a function, choose a branch when the list is empty, and loop through the rest. That combination is enough to build the automations in the next layer.
