Conditions

The idea

A condition chooses a branch. if runs its block only when the test is true. else if tries another test when earlier ones were false. else runs when none of the tests were true.

=== asks whether two values are the same kind and the same value. > and < compare numbers. && means both sides must be true. || means either side may be true.

Why it matters

Automation is full of branches: if the file is missing, stop; if the status is 200, continue; if the heading is absent, fail the test. Conditions are how a program notices.

A picture to hold

A trail with signed forks. The sign is the test. You take one fork. You do not walk both. else is the fork marked “none of the above.”

A small example

What you should see
Hot enough for tea.

Line by line

  1. const temperatureC = 92;Store the number you will test.
  2. if (temperatureC >= 100) {The parentheses hold the test. >= means greater than or equal. 92 is not greater than or equal to 100, so this block is skipped.
  3. } else if (temperatureC >= 80) {Because the first test was false, this test runs. 92 is at least 80, so the engine enters this block.
  4. console.log("Hot enough for tea.");This is the only print that runs. The other branches are skipped.
  5. } else {This would run only if both tests above were false. They were not, so it is skipped.

Try it yourself

Set temperatureC to 70, then to 100, and run the file each time. You should see Still heating. and then Boiling.. Add a second test of your own: print Too cold. when the number is below 40, and make sure your branch order still makes sense.

Common mistakes

  • Writing = inside an if when you meant ===. One equals sign stores a value.
  • Using ==. It converts types before comparing, so "92" == 92 is true. Prefer ===, which requires the same type and the same value.
  • Forgetting braces around a branch and attaching the wrong following line. Put each branch in { } while you are learning.

Recap

if, else if, and else choose one branch. === compares. >= compares numbers. Only the matching branch runs.
