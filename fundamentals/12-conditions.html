Layer 01 · Lesson 12 of 17

Conditions

One idea. if picks one path. The other paths stay quiet.

Start with a normal day

A trail has signed forks. You read the first sign. If it matches, you take that path. You leave the other paths alone.

The water is at 92 degrees. The first sign says “100 or more: boiling.” That sign does not match. The next sign says “80 or more: hot enough for tea.” That sign matches. You stop there.

New words

One temperature. Three possible messages. Only one message is shown.

condition
A test that is true or false, used to choose a path.
if
Run the steps inside its braces only when the test is true.
else if
Try another test when the earlier tests were false.
else
The path for “none of the signs matched.”
( )
Parentheses hold the test, right after if.
{ }
Curly braces hold the steps of one path.
>=
Asks “is the first number at least as big as the second?”
===
Asks “are these the same?” One equals sign stores. Three equals signs ask. Two equals signs, ==, also convert kinds before asking, so avoid them.

The steps, before any program

  1. Remember the temperature: 92.
  2. If it is 100 or more, say “Boiling.”
  3. Otherwise, if it is 80 or more, say “Hot enough for tea.”
  4. Otherwise, say “Still heating.”

92 matches the second sign. The program says that one sentence and skips the others.

The same steps, written as a program

Read the four steps again. Each if or else if is a sign on the trail. The braces are the path you take when the sign matches.

What you should see
Hot enough for tea.

What each line is saying

  1. const temperatureC = 92;Store the number you will test.
  2. if (temperatureC >= 100) {The parentheses hold the test. 92 is below 100, so this path is skipped.
  3. } else if (temperatureC >= 80) {The first test was false, so this test runs. 92 is at least 80, so this path is taken.
  4. console.log("Hot enough for tea.");This is the only line that shows a message.
  5. } else {This path would run if both tests above were false. They were not, so it stays quiet.

Try it

The box starts at 70, which prints “Still heating.” Change 70 to 100, then to 30. Each run shows one sentence.

Practice. Change the number. One message appears each time.

Easy to mix up

  • Inside a test, three equals signs ask a question. One equals sign stores a value.
  • == converts kinds before it asks, so the text "92" and the number 92 can count as the same. Use ===.
  • Put each path’s steps inside { }. A missing pair of braces can attach the next line to the wrong path.

Remember

if, else if, and else choose one path. The test sits in parentheses. Only the matching path runs.
