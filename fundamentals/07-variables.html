Layer 01 · Lesson 7 of 17

Variables

One idea. A variable is a name stuck to a value, so you can use that value again.

Start with a normal day

A jar has a label. The label is a name you chose. What is inside the jar is the value.

Some labels can be moved onto a new jar. let is that kind of name. You may put a new value under the same name later.

const is a label stuck to this jar. You will keep this name on this value. The spelling of the name has to match every time you use it.

New words

The program stores a count and a kind of kettle. These are the only new marks.

variable
A name attached to a value.
value
The thing stored under the name. A number, or a piece of text.
let
Create a name whose value you may replace later.
const
Create a name you will keep on this same value. Replacing it stops the program.
=
One equals sign stores a value under a name. It asks no question.
console.log
Show the current value on the screen.

The steps, before any program

  1. Name a count cups and store 1.
  2. Add 1 to that count and store the result under the same name.
  3. Name the kettle and store the word electric. Keep that name where it is.
  4. Show the count, then show the kettle.

The program writes those four steps with let, const, and one equals sign.

The same steps, written as a program

Read the four steps again. Each line below is one of them. The names cups and kettle are yours. The helper only cares that the spelling matches.

What you should see
2
electric

What each line is saying

  1. let cups = 1;Create the name cups and store the number 1. One equals sign stores.
  2. cups = cups + 1;Read the current number, add 1, and store the result under the same name. cups is now 2.
  3. const kettle = "electric";Create the name kettle and store the text electric. A later line that stores a new kettle would stop the program.
  4. console.log(cups);Show the number stored in cups. That number is 2.
  5. console.log(kettle);Show the text stored in kettle.

Try it

The box starts a score at 0, adds 10, then adds 5. Press Run. You should see 15.

Practice. The name score keeps the running total.

Easy to mix up

  • One equals sign stores a value. Asking “are these the same?” uses three equals signs, ===. That spelling arrives with choices, a few lessons from now.
  • cup and cups are two different names. The spelling has to match.
  • Use let and const. An older spelling, var, is loose about where the name can be seen.

Remember

let names a value you may replace. const names a value you will keep. One equals sign stores. The spelling of the name has to match.
