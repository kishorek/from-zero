Variables

One idea. A variable is a name attached to a value.

The idea

A variable is a name you choose for a value, so you can use the value again. let creates a name whose value may be replaced later. const creates a name you will not reassign.

The name is for you and for later lines. The engine does not care that you called it cups. It cares that the spelling matches wherever you use it.

Why it matters

Without names, a program is a trail of loose values. With names, you can talk about “the cup count” in one place and change it once. Tests and scripts are mostly names pointing at pages, files, and results.

A picture to hold

A jar with a label. The label is the variable name. What is inside is the value. let means you may empty the jar and put something else in. const means the label stays stuck to this jar. You can still change the insides of an object later. You may not peel the label off and stick it on a different jar.

A small example

What you should see
2
electric

Line by line

  1. let cups = 1;Create the name cups and store the number 1. One equals sign stores. It does not compare.
  2. cups = cups + 1;Read the current value, add 1, and store the result back under the same name. cups is now 2.
  3. const kettle = "electric";Create kettle and store text. A later line kettle = "gas" would stop the program, because const refuses reassignment.
  4. console.log(cups);Print the current value of cups, which is the number 2.
  5. console.log(kettle);Print the text stored in kettle.

Try it yourself

Start from 0, add 10, add 5, and print the score. You should see 15.

Practice. The second addition is the piece to check.

Common mistakes

  • Using one equals sign to ask “are these the same?”. = stores. === compares, and it arrives in the conditions lesson.
  • Misspelling a name on a later line. cup and cups are two different names.
  • Reaching for var. It is older JavaScript. It leaks out of blocks in surprising ways. Use let and const.

Recap

let names a value you may replace. const names a value you will not reassign. The spelling of the name has to match every time you use it.
