What is a computer program?

The idea

A computer program is a list of instructions you write down before anything runs. The computer starts at the top and follows the list. It does each step, then the next step, until the list ends or a step tells it to stop.

The computer does not supply missing steps. If you forget to say “open the cupboard,” a person might guess. A computer will not. The quality of a program is the quality of the instructions.

Why it matters

Every script in this course is a program, including the Playwright tests at the end. Those tests feel less mysterious once you can see them as a list: open this page, find this heading, check this sentence.

A picture to hold

A player piano roll is a program. The holes are instructions. The piano is the computer. The piano has no opinion about the song. It plays the holes you punched, including a wrong note, the same way, every time you turn the crank.

A small example

This program has three instructions. Each one asks Node.js to print a line. Save it as tea.js. If Node.js is not installed yet, read the file now and run it after lesson 5.

What you should see
Boil water.
Add tea.
Wait.

Line by line

  1. console.log("Boil water.");console.log prints the text between the quotes. The parentheses hold what you want printed. The semicolon ends the instruction.
  2. console.log("Add tea.");The second instruction runs after the first one has finished. Nothing in this file runs at the same time as something else.
  3. console.log("Wait.");The third instruction. Three ordered instructions are already a complete program.

Try it yourself

Create morning.js. Print three lines that describe how you make breakfast, in the order you do them. Run node morning.js. The terminal should show those three lines in that same order.

Common mistakes

  • Writing a paragraph and expecting the computer to pick the actions out of it. A program is separate instructions.
  • Leaving out a step because it feels obvious. The computer does not share your habits.
  • Changing the order and expecting the same result. Order is part of the program.

Recap

A program is a prepared list of instructions. The computer follows that list in order. It does not add common sense between the lines.
