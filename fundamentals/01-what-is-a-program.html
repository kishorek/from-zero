What is a computer program?

One idea. A program is a list of steps, written down before the computer starts.

Start with a normal day

Think about making tea. You already know the order. You do not invent the next step while the kettle is boiling.

First, boil the water. Then add the tea. Then wait.

A person might fill in a missing step from habit. A computer only does the steps you wrote, in the order you wrote them. A wrong step gets followed too, the same way, every time.

New words

The program below uses these words. Read them before you look at the program.

program
A list of steps prepared ahead of time.
instruction
One step in that list. One line, in the program below.
console.log
The spelling for “show this on the screen.”
quotes
The marks " around words. They mean “this is text. Show it as it is.”
parentheses
The marks ( and ). They hold the text you want to show.
semicolon
The mark ; at the end of a line. It means “this step is finished.”

The steps, before any program

  1. Show the words “Boil water.”
  2. When that is finished, show the words “Add tea.”
  3. When that is finished, show the words “Wait.”

Three steps. That is already a whole program. Step 2 waits until step 1 has finished.

The same steps, written as a program

Read the three steps once more. The box below is those same steps. Each line is one step. You can run it in the practice box on this page. You do not need to install anything yet.

What you should see
Boil water.
Add tea.
Wait.

What each line is saying

  1. console.log("Boil water.");Show the text between the quotes. The parentheses hold that text. The semicolon ends the step.
  2. console.log("Add tea.");The second step. It runs after the first step has finished.
  3. console.log("Wait.");The third step. Then the list is done.

Try it

The box already has three breakfast steps. Change the words to your own breakfast, then press Run. You should see your three lines, in the same order.

Practice. Three lines. Your words, in the order you do them.

Easy to mix up

  • A paragraph is one block of words. A program is separate steps. Write one step on each line.
  • A step that feels obvious still has to be written down.
  • The order is part of the program. Swap two lines, and the result changes.

Remember

A program is a list of steps written ahead of time. The computer follows that list from top to bottom.
