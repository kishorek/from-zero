Layer 01

Programming fundamentals

This layer teaches what a program is, before any tool or library. You will meet instructions, code, languages, JavaScript, Node.js, and the pieces every later script is built from: values, lists, records, decisions, repetition, functions, and errors.

Read these sixteen lessons in order. Each one uses only ideas from the lessons before it. Every lesson has a practice box. Use the box before you think about installing anything.

  1. 01
    What is a computer program?

    A program is a list of instructions prepared ahead of time.

  2. 02
    What is code?

    Code is the written form of a program, in a strict spelling.

  3. 03
    How does a computer understand instructions?

    A translator turns your text into steps the machine can carry out.

  4. 04
    What is a programming language?

    A language is an agreed set of rules for writing instructions.

  5. 05
    What are JavaScript and Node.js?

    JavaScript is the language. Node.js runs it outside the browser.

  6. 06
    Your first program

    Make a folder, write a file, run it with node.

  7. 07
    Variables

    A variable is a name attached to a value.

  8. 08
    Numbers and text

    Numbers calculate. Text is a string of characters. Quotes make text.

  9. 09
    Arrays

    An array is an ordered list. The first item is index 0.

  10. 10
    Objects

    An object groups named values into one record.

  11. 11
    Conditions

    if, else if, and else choose which instructions run.

  12. 12
    Loops

    A loop repeats instructions for each item, or until a test fails.

  13. 13
    Functions

    A function is a named block you can run whenever you call it.

  14. 14
    Errors

    An error stops the current work and points at a line.

  15. 15
    Debugging

    Debugging is gathering evidence about what the program actually did.

  16. 16
    Putting everything together

    One small program uses names, a list, a function, a branch, and a loop.
