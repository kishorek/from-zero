What is code?

One idea. Code is the exact text the computer reads. Comments are notes it skips.

The idea

Code is the text of a program. It is written in a fixed spelling so a translator program can read it. The ideas in your head are not code yet. Code is the marks on the screen: words, quotes, parentheses, and semicolons.

People often say “code” when they mean the whole activity of programming. In this course, code means the text. The program is what that text asks the computer to do.

Why it matters

Small spelling differences change the program. A missing quote is not a style choice. It makes the translator stop. Learning to look closely at the text saves hours later.

A picture to hold

Sheet music is not the sound. It is a written form of the sound, with rules about notes and rests. Two musicians can play the same page and get the same song because they share those rules. Code works the same way between you and the computer.

A small example

Lines that start with // are comments. They are code for humans. The translator skips them. The other lines are instructions.

What you should see
Hello

Line by line

  1. // A note to the next reader. The computer skips this line.Two slashes start a comment. Everything after them on that line is ignored when the program runs.
  2. console.log("Hello");This is an instruction. The quotes mark text. Without the quotes, Hello would be read as a name, not as a sentence.

Try it yourself

Add a comment above the print. The comment should not appear when you run it. Then delete the last quote, run, read the error, and put the quote back.

Practice. A comment starts with two slashes.

Common mistakes

  • Treating comments as instructions. A comment explains. It does not run.
  • Using curly quotes from a word processor. Programming quotes are straight quotes: ".
  • Calling any English sentence code. Code follows the spelling rules of a language.

Recap

Code is the written text of a program. Comments are for people. Instructions are for the computer. The spelling is part of the meaning.
