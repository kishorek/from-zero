What is code?

One idea. Code is the written text of a program. A comment is a note the computer skips.

Start with a normal day

A recipe card is not the meal. It is the meal written down, with rules about the order of the lines.

Two people can follow the same card and get the same meal, because they share those rules. Code is that card. The program is the meal the computer makes from it.

You can also write a note in the margin for the next person. The cook skips the margin.

New words

Read these before the program. Each one is a small mark on the page.

code
The text of a program: the words and marks the computer reads.
comment
A note for a person. The computer skips it.
//
Two slashes. They start a comment. The rest of that line is the note.
console.log
The spelling for “show this on the screen.”
quotes
The marks " around text. They mean “show these words as they are.”
semicolon
The mark ; at the end. It means “this step is finished.”

The steps, before any program

  1. Leave a note: this line greets someone.
  2. Show the word Hello.

The note is for you. The second step is the only one the computer follows.

The same steps, written as a program

Read the two steps again. The first line of the program is the note. The second line is the greeting. The greeting is the only thing that should appear.

What you should see
Hello

What each line is saying

  1. // A note to the next reader. The computer skips this line.This is a comment. Two slashes mark the note. Nothing from this line appears on the screen.
  2. console.log("Hello");Show the text Hello. The quotes mark that text. The semicolon ends the step.

Try it

Press Run. You should see Hello, and you should not see the note. Then delete the last quote, press Run, read the message, and put the quote back.

Practice. The note starts with two slashes. Hello is the step.

Easy to mix up

  • A comment is a note. It does not run. An instruction is a step. It does run.
  • Use straight quotes, ". Curly quotes from a word processor are a different mark, and the computer rejects them.
  • An English sentence becomes code only when it follows the spelling rules.

Remember

Code is the written text. Comments are for people. Instructions are for the computer. The spelling is part of the meaning.
