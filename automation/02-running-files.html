Running JavaScript files with Node.js

The idea

node file.js starts Node.js, asks it to read that file from the top, and waits until the program finishes. When it finishes, it returns an exit code to the shell. Code 0 means “finished as planned.” Any other code means “something was wrong.”

You can also type node with no file. That opens a prompt, a REPL, where each line runs immediately. It is useful for a quick question. Real programs live in files so you can run them again.

A file that uses import needs to be a module. The simple rule for this course: save those files as .mjs and run node file.mjs. Plain scripts with no import can stay .js.

Why it matters

Playwright’s test command is another program you run from the shell. It also uses exit codes: 0 when tests pass, 1 when they fail. Learning that signal now makes the later reports easier to trust.

A picture to hold

Handing a recipe card to a cook and waiting by the door. Exit code 0 is the cook nodding. Any other code is the cook shaking their head. The nod is for the shell, so other tools can react. The printed lines are for you.

A small example

What you should see
Running with Node v20.x.x  (your number may be newer)

Line by line

  1. console.log("Running with Node " + process.version);process.version is text like v22.14.0. Plus joins your sentence to that text.
  2. process.exitCode = 0;Set the code the process will hand back when it ends. Setting it does not stop the program immediately. process.exit(0) would stop at once, and it can cut off work that is still finishing, so prefer exitCode.

Try it yourself

Run node version.js and then, in the same terminal, print the exit code. On macOS and Linux that command is echo $?. On Windows PowerShell it is echo $LASTEXITCODE. You should see 0. Change the file to process.exitCode = 2, run it again, and confirm the shell now reports 2.

Common mistakes

  • Opening the REPL and pasting a whole file without saving it. You then have nothing to rerun tomorrow.
  • Calling process.exit(1) in the middle of a script that still needs to close a file. Set process.exitCode and let the script reach its end.
  • Naming a module file.js and using import without telling Node.js it is a module. Use .mjs until a later lesson sets "type": "module".

Recap

node file.js runs a file to the end. Exit code 0 means success. Other codes mean failure. .mjs is the ending for a file that uses import.
