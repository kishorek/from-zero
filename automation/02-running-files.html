Running JavaScript files with Node.js

One idea. node runs a file. A final number says whether it finished as planned.

Start with a normal day

You hand a recipe card to a cook and wait by the door. The cook nods, or shakes their head.

The nod is a number for the terminal. The printed lines are the words for you. Both happen. They are different messages.

New words

The file shows one sentence and then sets that final number.

node file.js
Start Node.js and ask it to read that file from the top, until the file ends.
exit code
The final number handed back to the terminal. 0 means finished as planned. Any other number means something was wrong.
process.version
Text naming the Node.js you are running, such as v22.14.0.
process.exitCode
Where you store that final number. Setting it does not stop the file immediately. The file still finishes its remaining lines.
process.exit
Stop immediately with a number. It can cut off work that is still finishing. Prefer exitCode on this page.
.js and .mjs
A plain file ends in .js. A file that uses import (a later lesson) is saved as .mjs so Node.js treats it as a module, a file that can share recipes.
REPL
What you get if you type node with no file name. Each line runs at once. Fine for a question. A real program lives in a file so you can run it again.

The steps, before any program

  1. Show a sentence that includes the Node.js version.
  2. Set the final number to 0, meaning finished as planned.
  3. Let the file end. The terminal receives that 0.

The practice box also lets you change 0 to 2 and see the failure number.

The same steps, written as a program

Read the three steps again. The first line is the sentence for you. The second line is the number for the terminal.

What you should see
Running with Node v20.x.x  (your number may be newer)

What each line is saying

  1. console.log("Running with Node " + process.version);Show a sentence. The plus sign glues your words to the version text.
  2. process.exitCode = 0;Store 0 as the final number. The file does not stop on this line. When it ends, the terminal receives 0.

Try it

Press Run. You should see the version sentence and exit code 0. Change 0 to 2 and run again. The exit code should be 2.

Practice. 0 means finished as planned. 2 means something was wrong.

Easy to mix up

  • Typing a whole program into node with no file leaves you nothing to run tomorrow. Save the file.
  • process.exit(1) stops at once. process.exitCode = 1 lets the file finish, then reports the number.
  • A file that uses import is saved as .mjs in this course. A file with no import can stay .js.

Remember

node file.js runs a file to the end. Exit code 0 means it finished as planned. Any other number means something was wrong.
