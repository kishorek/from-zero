Transforming lists

The idea

map builds a new array by turning each item into something else. filter builds a new array of the items that pass a test. reduce folds the whole array into one value, such as a total.

Each of these accepts a function. That function is a callback: a function you hand over, which the array method calls for you. Arrow functions are the usual spelling here. The original array stays as it was.

Why it matters

Automation is “do this to every row that matches.” for...of can do it. map and filter name the intention, and they pair well with the lists you will pull from files and from web pages.

A picture to hold

A kitchen pass. map plates every dish according to one rule. filter sends back only the plates a diner asked for. reduce is the bill: one number folded from every plate. The order ticket (prices) is still on the counter.

A small example

What you should see
[ 4.4, 2.75, 9.9 ]
[ 4, 9 ]
15.5

Line by line

  1. const prices = [4, 2.5, 9];The source list. It is not modified by the three lines below.
  2. const withTax = prices.map((price) => price * 1.1);map calls the arrow once per price. The arrow’s return value becomes the new item. Three prices in, three taxed prices out.
  3. const expensive = prices.filter((price) => price >= 4);filter keeps items whose arrow returns true. 2.5 fails the test and is left out.
  4. const total = prices.reduce((sum, price) => sum + price, 0);reduce starts sum at 0. Each price is added to sum. The final sum is the total.

Try it yourself

From [" Tea ", "milk", " "], trim every string, drop the empty ones, and lowercase the rest. Chain map, then filter. The result should be ["tea", "milk"]. Print the original array last and confirm it is unchanged.

Common mistakes

  • Forgetting that the arrow in map must return the new item. An arrow with braces and no return fills the new array with undefined.
  • Using map when you only want to keep some items. That is filter. Using filter when you want to change the items. That is map.
  • Skipping the starting value in reduce on an empty array. prices.reduce(...) with no 0 throws if prices is empty. Pass the starting value.

Recap

map transforms every item. filter keeps some. reduce folds them into one value. All three return something new and take a callback.
