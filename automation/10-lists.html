Transforming lists

One idea. map builds a new list by changing each item. filter keeps some items. reduce combines the list into one value.

Start with a normal day

Three prices sit on a scrap of paper: 4, 2.5, and 9. You do not scribble on the scrap.

You write a new list with a little tax on each price. You write another list that keeps only the prices that are 4 or more. Then you add the prices into one total. The scrap is still the scrap.

New words

The small program uses a list of prices. The practice box cleans a list of words. Read these before the program.

const
A name stuck to a value. The name prices stays on the original list.
[ ]
Square brackets hold a list. Commas separate the items. [4, 2.5, 9] is three prices.
trim
Cut spaces off both ends of a piece of text. Spaces in the middle stay. The practice box uses this.
toLowerCase
Make new text with capital letters turned into small letters. Tea becomes tea.
map
Build a new list by changing each item. Three prices go in, and three new prices come out. The old list stays.
filter
Keep some items. The new list holds only the items that pass a test. The old list stays.
reduce
Combine the list into one value. The total starts at 0. Each price is added in.
=>
An arrow. It writes a short function. The name in parentheses is the current item. The value after the arrow is what you hand back.
*
Multiply two numbers. price * 1.1 makes each price a bit larger.
>=
Ask whether the first number is at least as big as the second. The answer is true or false.
+
Add two numbers.
console.log
Show a value on the screen.
function
A recipe written with the word function. The practice box uses this spelling. map and filter call it once per item.
return
Hand a value back from the function, and stop there. With no return, nothing useful comes back.
length
How many characters are in a piece of text. Blank text has length 0.
>
Ask whether the first number is bigger than the second. length > 0 asks whether the text is not blank.
true and false
The only two answers a yes-or-no question can give.

The steps, before any program

  1. Store the prices 4, 2.5, and 9.
  2. Build a new list by changing each item. Multiply each price by 1.1.
  3. Keep some items. Keep a price only when it is at least 4.
  4. Combine the list into one value. Start at 0, and add each original price.
  5. Show the taxed list.
  6. Show the prices that were kept.
  7. Show the total.

The original list is never rewritten. Each step stores a new result.

The same steps, written as a program

Read the steps again. map builds the taxed list. filter keeps the big prices. reduce combines the prices into one total. The last three lines show those results.

What you should see
[ 4.4, 2.75, 9.9 ]
[ 4, 9 ]
15.5

What each line is saying

  1. const prices = [4, 2.5, 9];Store the original list of three prices. The later lines do not change this list.
  2. const withTax = prices.map((price) => price * 1.1);Build a new list by changing each item. Each price is multiplied by 1.1. The list named prices stays as it was.
  3. const expensive = prices.filter((price) => price >= 4);Keep some items. A price stays only when it is at least 4. 2.5 is left out.
  4. const total = prices.reduce((sum, price) => sum + price, 0);Combine the list into one value. The total starts at 0. Each price is added to it. The last total is 15.5.
  5. console.log(withTax);Show the new taxed list.
  6. console.log(expensive);Show the prices that were kept.
  7. console.log(total);Show the one combined total.

Try it

Press Run. Each piece of text is trimmed and put in small letters. Blank text is dropped. You should see tea, then milk. The second list is the original, spaces and all.

Practice. Change each item, then keep the ones that are not blank.

Easy to mix up

  • map builds a new list by changing each item. filter keeps some items. They do different jobs.
  • The arrow here has no braces. The value after the arrow comes back. Add braces and forget return, and each new item has no value.
  • reduce combines the list into one value. The 0 is the start of that value. On an empty list, leaving out the start stops the program with an error.

Remember

map builds a new list by changing each item. filter keeps some items. reduce combines the list into one value. The original list stays.
