Cleaning up text

The idea

Text from files and websites is messy. trim removes spaces, tabs, and newlines from both ends. toLowerCase makes comparison calmer. split cuts one string into an array. includes asks whether a smaller string sits inside.

None of these change the original string. Strings are immutable: methods return a new string. You store that new string if you want to keep it.

Why it matters

A task list copied from email, a heading with a trailing space, a comma-separated export: automation spends more time cleaning text than inventing it. Playwright’s accessible names are also text, and an extra space can make a lookup miss.

A picture to hold

Washing vegetables before cooking. The recipe is simple. The dirt comes from the trip. trim and split are the wash. You still cook the same vegetables. You just stop biting into the crate.

A small example

What you should see
ada lovelace
[ 'tea', 'milk', 'sugar' ]
true

Line by line

  1. const clean = messy.trim();trim returns a new string with the outer spaces gone. messy itself is unchanged.
  2. const parts = "tea, milk, sugar".split(", ");Cut on the comma-space. You get three strings in an array. The separator is not kept.
  3. console.log(clean.toLowerCase());A new string in lowercase. Useful before you compare names that may arrive as Ada or ada.
  4. console.log("Hello".includes("ell"));includes returns a boolean. ell sits inside Hello, so the answer is true.

Try it yourself

Start from " Tea, Milk, tea ". Trim it, split on ", ", lowercase each piece, and print the array. You should see tea twice. Then keep only the unique words. A direct way: walk the array and push a word when the result does not already includes it.

Common mistakes

  • Comparing "Ada" and "ada" with === and treating the mismatch as a mystery. Case is part of the text.
  • Splitting on "," when the file has ", ", and then wondering about the leftover spaces. Include the spaces in the separator, or trim each piece.
  • Expecting trim to remove spaces between words. It only clears the two ends.

Recap

trim, toLowerCase, split, and includes return new strings or arrays. Use them to make messy input predictable before you branch on it.
