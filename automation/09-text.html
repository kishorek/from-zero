Cleaning up text

One idea. Trim the edges, cut the text into words, and compare it in small letters.

Start with a normal day

A name shows up with spaces before it and spaces after it. A shopping note is one line. A comma and a space sit between tea, milk, and sugar. One note says Tea. Another says tea.

You wipe the spaces off the ends of the name. You cut the shopping line into separate words. You make the letters small, so Tea and tea count as the same word.

New words

The small program cleans a name and cuts a shopping line. The practice box walks a list of words. Read these before the program.

const
A name stuck to a value. The name stays on that text.
trim
Cut spaces, tabs, and newlines off both ends. Spaces between words stay. You get new text. The old text stays as it was.
toLowerCase
Make new text with capital letters turned into small letters. Tea becomes tea.
split
Cut one piece of text into a list. You name the cut, such as a comma and a space. The cut itself is not kept.
join
Glue a list back into one piece of text. You choose what goes between the pieces. split cuts. join puts the pieces back. This program does not call join.
includes
Ask whether smaller text sits inside bigger text. On a list, ask whether an item is already there. The answer is true or false.
true and false
The only two answers a yes-or-no question can give.
console.log
Show a value on the screen.
map
Build a new list by changing each item. The practice box uses it so each word comes back in small letters. The old list stays.
function
A small recipe. The name in parentheses is the current item. map calls the recipe once per item.
return
Hand a value back from that recipe, and stop there.
[ ]
Square brackets hold a list. Commas separate the items. [] is a list with nothing in it yet.
for...of
Take each item in a list, one at a time. for (const word of parts) takes each word in parts.
if
Do the next step only when a test is true.
!
Not. It flips a yes-or-no answer. !unique.includes(word) means this word is not already in the list.
push
Add one item at the end of a list.

The steps, before any program

  1. Start with a name that has spaces on both ends.
  2. Cut those spaces off the ends, and keep the new text.
  3. Cut the line tea, milk, sugar into separate words. The cut is a comma followed by a space.
  4. Show the cleaned name in small letters.
  5. Show the three words.
  6. Ask whether ell sits inside Hello, and show the answer.

Each step gives you new text or a new list. The text you started with stays as it was.

The same steps, written as a program

Read the six steps again. The first lines store the messy name, the cleaned name, and the cut-up shopping line. The last three lines show the answers.

What you should see
ada lovelace
[ 'tea', 'milk', 'sugar' ]
true

What each line is saying

  1. const messy = " Ada Lovelace ";Store a name that still has spaces on both ends. The quotes mark the text. The spaces inside the quotes are part of it.
  2. const clean = messy.trim();Cut the spaces off both ends, and store that new text as clean. The name in messy is unchanged.
  3. const parts = "tea, milk, sugar".split(", ");Cut the shopping line where a comma is followed by a space. You get three words. The comma and the space are not kept.
  4. console.log(clean.toLowerCase());Show the cleaned name in small letters. You see ada lovelace.
  5. console.log(parts);Show the list of three words.
  6. console.log("Hello".includes("ell"));Ask whether ell sits inside Hello. It does, so the answer is true.

Try it

Press Run. The first list is tea, milk, and tea again, in small letters. The second list keeps tea once, then milk.

Practice. trim clears the ends. It does not clear spaces between words.

Easy to mix up

  • "Ada" and "ada" are not the same text. includes cares about capital letters. Make both sides small letters before you compare.
  • Cutting on a comma alone leaves a space on the next word when the line used a comma and a space. Put that space in the cut, or trim each piece.
  • trim clears only the two ends. Spaces between words stay.

Remember

trim clears the two ends. toLowerCase makes small letters. split cuts text into a list. join glues a list back into text. includes asks whether one piece sits inside another. map builds a new list by changing each item. The original text stays as it was.
