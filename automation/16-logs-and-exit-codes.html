Logs and exit codes

One idea. People read the message. The shell reads the exit code.

Start with a normal day

A front desk keeps two trays and a lamp. Ordinary notes go in one tray. Problems go in the other.

The lamp is green when the job finished as planned. It is red when it did not. People read the trays. The next machine looks only at the lamp.

New words

The script reads one extra word from the command. No word is a failure. A word gets a greeting.

shell
The program that started your script. It reads the exit code. It does not read your notes.
log
A written note of what happened. console.log prints an ordinary note.
console.error
Prints a problem note apart from the ordinary notes.
exit code
An exit code is a final number for the program that started you. 0 means it finished as planned. 1 means it did not.
process.exitCode
Where the script stores that number. The script can then end on its own.
process.exit
Stops the program on that line. Prefer process.exitCode unless you must stop immediately.
process.argv
The words used to start the script. process.argv[2] is the first word after the script name. The earlier words name the program itself.
if
A test. The lines inside run only when the test is true.
!
Means not. !name is true when no word was typed.
else
The other path. It runs when the if test was not true.

The steps, before any program

  1. Read the word typed after the script name.
  2. If that word is missing, print a problem and set the exit code to 1.
  3. If that word is there, print a hello and set the exit code to 0.

The same steps, written as a program

Read the three steps again. One file does both paths. A missing word takes the first path. A word takes the second.

What each line is saying

  1. const name = process.argv[2];Take the first word typed after the script name.
  2. if (!name) {The ! means not. This path runs when that word is missing.
  3. console.error("Missing name.");Print a short problem note, apart from ordinary notes.
  4. process.exitCode = 1;Set the exit code to 1. This did not finish as planned.
  5. } else {A word was typed. Take this other path.
  6. console.log("Hello, " + name);Print an ordinary hello. A person reads this.
  7. process.exitCode = 0;Set the exit code to 0. It finished as planned. Leaving the number unset also means 0. Setting it makes success as clear as failure.

Try it

The box is stricter than the file above. One letter counts as missing. Run it with Al. You should see a hello, and the exit code is 0. Clear the word, or type one letter. The exit code is 1.

Practice. Al is long enough. A is not.

Easy to mix up

  • A cheerful note with exit code 1, or a problem note with exit code 0. The shell trusts the number, not the sentence.
  • Printing a failure with console.log mixes it into the ordinary notes. console.error keeps problems apart.
  • process.exit(1) stops the whole program on that line. In a function another file uses, that can close their script too. Set process.exitCode, then return.

Remember

console.log is for ordinary notes. console.error is for problems. An exit code is a final number for the program that started you. 0 means it finished as planned. People read the text. The shell reads the number.
