async and await

One idea. await pauses one function until a later answer arrives.

Start with a normal day

You put the kettle on. You stand there until it sings. You do not leave a note and walk off.

Other people in the room can still move. Only you are paused. When the kettle sings, you pour, and you do the next thing on your list.

New words

Two words name that pause. The program prints a line, waits a moment, and prints the next line.

async
A mark on a function. That function may use await, and it returns a promise.
await
await pauses that one function until the later answer arrives. It does not pause the whole computer.
promise
A ticket for an answer that is not here yet. delay hands one back.
setTimeout
Ask the computer to run a function after a number of milliseconds. 200 milliseconds is a fifth of a second.
arrow
=> is a short way to write a function. The practice box writes function instead, which is the same idea.

The steps, before any program

  1. Make a short wait that hands back a ticket.
  2. Mark a function so it is allowed to pause.
  3. Print start.
  4. Pause that one function until the wait is over.
  5. Print the line after the wait.
  6. Call the function. Otherwise nothing starts.

The pause is only inside that function. The lines under the pause stay in the order you meant.

The same steps, written as a program

Read the steps again. The box is one file. It prints start, pauses that function, and prints after the wait.

What you should see
start
after the wait

About a fifth of a second passes between the two lines. The timer only makes the pause easy to see.

What each line is saying

  1. function delay(ms) {Hand back a promise that finishes after ms milliseconds. The pause is the point.
  2. setTimeout(resolve, ms);Ask the computer to call resolve after that many milliseconds. That call fulfills the promise.
  3. async function main() {Mark this function so it may pause. It returns a promise.
  4. console.log("start");Print start now, before the pause.
  5. await delay(200);Pause this one function until the later answer arrives. The next line does not run before that.
  6. console.log("after the wait");Print this only after the pause. Inside this function, the lines stay in the order you wrote.
  7. main();Start the function. If you never call it, nothing happens.

Try it

Run the box. start prints, then after the wait. The wait is short on purpose. Only that one function was paused.

Practice. await delay pauses main, not the whole computer.

Easy to mix up

  • Using await in a function that is not marked async. The program will not run.
  • Forgetting to call the function, or forgetting to await its promise. The script can finish before the work does.
  • Waiting a fixed time just in case. Wait for the answer you actually need.

Remember

async marks a function that can pause. await pauses that one function until the later answer arrives.
