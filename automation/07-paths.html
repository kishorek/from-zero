Paths and folders

The idea

A path is the address of a file or folder. On macOS and Linux the pieces are separated by /. On Windows the separator is \. If you glue strings by hand, you will get it wrong on one of those systems.

node:path knows the separator. path.join(folder, "notes", "today.txt") builds the address. path.dirname takes the folder part of a file address. path.basename takes the file name.

Why it matters

Automation walks folders: every .txt in inbox, a report written to out. The bugs are almost always wrong addresses, not wrong ideas. A helper that joins pieces removes a whole family of those bugs.

A picture to hold

A street address written by someone who knows the city. You supply the city, the street, and the door. path.join inserts the right punctuation. You do not hand-draw the commas.

A small example

Line by line

  1. import path from "node:path";Load the whole path module under the name path. Default import, no braces, because the module presents one main object.
  2. const here = path.dirname(fileURLToPath(import.meta.url));import.meta.url is a URL. fileURLToPath turns it into a path string. dirname drops the file name and keeps the folder.
  3. const note = path.join(here, "notes", "today.txt");Join three pieces with the separator your operating system uses.
  4. console.log(path.basename(note));Print only today.txt. Useful when you want the name without the address.

Try it yourself

Print path.join(here, "..", "outside.txt") and also print path.resolve of that same join. .. means the parent folder. path.resolve turns the address into a full path with the .. folded in. Read both lines and say which folder outside.txt would live in.

Common mistakes

  • Building paths with folder + "/" + name. That breaks on Windows and breaks again if folder already ended with a slash.
  • Confusing dirname and basename. Directory is the folder. Base name is the last piece.
  • Assuming ./notes in a string always means “beside this script.” It means “beside the current working directory” unless you join it onto the script’s own folder.

Recap

A path is an address. path.join builds one. dirname is the folder. basename is the file name. Let the module place the slashes.
