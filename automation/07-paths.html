Paths and folders

One idea. A path is an address. Join the pieces. Do not glue slashes by hand.

Start with a normal day

You send a note to one desk. You name the building, the room, and the desk. Someone who knows the building writes the punctuation.

A file has an address too. You name the folder, the next folder, and the file. A helper writes the slashes.

New words

The file below builds an address beside itself. The practice box steps up to a parent folder. These words cover both.

path
The address of a file or a folder. The same name is the helper that builds addresses.
join
path.join puts the pieces together and places one slash between them. The slash is / on macOS and Linux. On Windows it is \.
import
A line that loads a tool. import path from "node:path" loads the whole helper and names it path. Braces, as in { fileURLToPath }, load one named tool.
node:path
The address helper that comes with Node. You do not install it.
fileURLToPath
Turns an address that starts with file: into a normal path.
node:url
Tools that come with Node for file: addresses. fileURLToPath comes from here.
import.meta.url
The address of the file that is running, written so it starts with file:.
const
A name for a value. here is the folder. note is the file address.
dirname
The folder part of a path. The file name is left off.
basename
The last piece of a path. For a file, that piece is the file name.
console.log
Show a value on the screen.
..
The parent folder. One step up.
resolve
path.resolve folds .. away and returns one full address.

The steps, before any program

  1. Find the folder this file sits in.
  2. Add notes and today.txt onto that address.
  3. Show the whole address.
  4. Show only the file name.

Each step is one small request. The helper places the slashes. You do not glue them by hand.

The same steps, written as a program

Read the four steps again. The file finds its own folder, then builds the address of today.txt inside notes.

What each line is saying

  1. import path from "node:path";Load the address helper and call it path.
  2. import { fileURLToPath } from "node:url";Load the tool that turns a file: address into a path.
  3. const here = path.dirname(fileURLToPath(import.meta.url));Take the address of this file, make it a path, then keep only the folder.
  4. const note = path.join(here, "notes", "today.txt");Build one address from that folder, notes, and today.txt.
  5. console.log(note);Show the full address. It changes with the folder the file lives in.
  6. console.log(path.basename(note));Show only today.txt.

Try it

Run the box. It joins /lab, .., and outside.txt. The first line still shows ... The second line is /outside.txt.

Practice. Join /lab, .., and outside.txt. Then fold the .. away.

Easy to mix up

  • Do not glue pieces with + and a slash. That breaks on Windows, where the mark is a backslash. It also breaks when a piece already ends with a slash.
  • dirname is the folder. basename is the last piece, the file name.
  • ./notes means beside the folder you were in when you started the file. It does not mean beside the file, unless you join it onto the folder that holds the file.
  • This box leaves .. in the joined line so you can see it. On your computer, path.join also folds a .. that sits between two pieces. path.resolve returns one full address.

Remember

A path is an address. path.join builds one from pieces. dirname is the folder. basename is the file name. Let the helper place the slashes.
