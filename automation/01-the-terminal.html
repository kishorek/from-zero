The terminal

One idea. The terminal is a window where you ask for one thing at a time.

Start with a normal day

Think of a service counter. You do not walk into the storeroom. You ask one question. The person answers. Then they wait for the next question.

The terminal is that counter. You type a short command. The computer answers. Then it waits.

New words

These commands move you around. The small program at the end asks the same “where am I?” question from JavaScript.

terminal
The text window where you type commands.
shell
The program behind that window. It reads a command, runs it, and prints the result.
folder
A place that holds files. A path is the address of a folder or a file.
pwd
“Where am I?” It prints the address of the folder you are in.
ls
“What is here?” It lists the names in that folder. It does not open them.
mkdir
“Make a folder.” mkdir notes creates a folder named notes.
cd
“Go into this folder.” cd .. goes up to the folder that contains this one.
process.cwd()
The same “where am I?” question, asked from a JavaScript file. cwd means current working directory, the folder you were in when you started the file.

The steps, before any program

  1. Ask which folder you are in.
  2. Ask what is in it.
  3. Make a folder named notes.
  4. Go into notes, and ask again where you are.

Each line is one request at the counter. The JavaScript file asks the same location question a second way.

The same steps, written as a program

Read the four steps again. The first box is what you type, one line at a time. The second box is a file. It shows a sentence, then the folder the file was started from.

What you should see
This script is running from:
/your/current/folder

What each line is saying

  1. pwdAsk for the address of the folder you are in. You type this in the terminal.
  2. lsList the names in that folder.
  3. mkdir notesCreate a folder named notes inside the current folder.
  4. cd notesGo into notes. The next command starts from there.
  5. console.log(process.cwd());From inside the JavaScript file, ask for that same folder and show it.

Try it

In the pretend terminal, type mkdir lab, then cd lab, then pwd. The last answer should end in lab.

Practice. One command, then Enter. Try mkdir lab, then cd lab, then pwd.


      
      

      

    

      
Easy to mix up

      
  • pwd belongs in the terminal. console.log belongs in a JavaScript file.
  • Going into a folder in one window leaves every other window where it was.
  • A long address is still just a folder. The last piece is the folder you are in.

      
Remember

      
The terminal takes one command at a time. pwd, ls, cd, and mkdir move you around. process.cwd() is that same folder, asked from JavaScript.
