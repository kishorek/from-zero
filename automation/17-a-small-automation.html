A script that turns a list into a report

One idea. Read a list, skip blank lines and notes, and write a numbered report.

Start with a normal day

You are the night clerk. The inbox is a text file named tasks.txt. Some slips are blank. Some start with #, which means “this is a note, not a task.”

You keep the real tasks, number them, write today’s date at the top, and file the packet as report.txt. If the inbox never arrived, you switch on a red lamp and you leave yesterday’s report alone.

New words

These words showed up in earlier lessons. This file uses them in one job, so here they are again.

import
Bring a tool in from another file. This script is saved as .mjs so import is allowed.
readFileSync
Read a whole file before the next line runs. "utf8" means “read it as ordinary text.” writeFileSync replaces a file with new text. Both come from node:fs, Node’s file tools.
path.join
Glue a folder and a file name into one path. path.dirname is the folder that holds a file.
import.meta.url
The address of this script. fileURLToPath turns that address into a normal path, so the script finds tasks.txt beside itself.
function
A named recipe. () => is a short function. The practice box writes function instead. Same idea.
split and trim
split("\n") breaks text into lines. trim removes spaces at both ends of a line.
map and filter
map builds a new list by changing each line. filter keeps the lines that pass a test.
startsWith
Asks whether a line begins with some text. ! in front flips the answer. A line that starts with # is a note.
&&
Both tests must pass. Here: the line has characters, and it is not a note.
forEach
Do one action for each item. index starts at 0, so the printed number is index + 1.
${ }
Inside backticks, ${dated} drops a value into the sentence.
Date
new Date() means now. Intl.DateTimeFormat turns that moment into words. dateStyle: "full" asks for the long form, such as Sunday, October 4, 2026.
try / catch
try attempts the read. If the file is missing, catch receives the error. error.message is the short explanation.
console.error
Print a problem sentence. It is separate from an ordinary console.log note.
exit code
process.exitCode = 1 tells the terminal something was wrong. Setting it does not stop the function, so the function also returns and skips the write.
readFile
In the practice box only, readFile and writeFile stand in for readFileSync and writeFileSync.

The steps, before any program

  1. Find tasks.txt in the same folder as the script.
  2. Read it as text. If it is missing, print an error, set the exit code to 1, and stop. Leave report.txt alone.
  3. Split the text into lines. Trim each line. Keep a line when it has text and does not start with #.
  4. Build the report. A dated title, a blank line, then 1. Buy milk and so on. If nothing remains, the report says No tasks today.
  5. Save that text as report.txt. Print how many tasks you wrote.

The same steps, written as a program

visibleTasks decides which lines count. reportText builds the packet as text. main is the only part that reads and writes files. Create tasks.txt beside the script, then run node report.mjs.

What you should see
Wrote 2 tasks.

Try it

Press Run. The report lists Buy milk as 1 and Reply to Ada as 2. The note and the blank line stay out. Add a third task and run again.

Practice. Lines that start with # are notes, not tasks.

Easy to mix up

  • A missing inbox should stop before any write. Writing anyway replaces yesterday’s report with an empty one.
  • Filter first, then number. A line that starts with # is a note, so it never becomes task 1.
  • The date, the filter, and the file write are three jobs. Each function does one, so a failure points at one job.

Remember

Read the list, drop blank lines and notes, number what remains, and write the report. A missing file sets exit code 1 and leaves the old report alone.
