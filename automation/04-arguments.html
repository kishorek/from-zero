Command-line arguments

One idea. Arguments are the extra words you type after the file name.

Start with a normal day

A food truck has one kitchen. The words you shout at the window are the order. The kitchen does not rewrite the recipe for each person. It reads the order.

In node greet.mjs Ada, the word Ada is the order. Tomorrow you can shout a different name and use the same file.

New words

The list of words has a surprising start. Your own word is not the first item.

argument
An extra word typed after the file name.
process.argv
The whole command, stored as a list of text. argv is short for argument values.
index 0
The first item. Here it is the address of node itself.
index 1
The address of your file.
index 2
The first word you added. In the example, Ada. The practice box also uses index 3 for the city.
!
Means “not.” !name is true when the name is missing.
<name>
A hint in a usage line. It means “put a value here.” You do not type the angle brackets.
exit code
The final number. 1 means this run was missing something it needed.

The steps, before any program

  1. Read the first extra word.
  2. If that word is missing, show how to run the file, and set the final number to 1.
  3. If the word is there, show “Hello,” and the word.

With Ada, you see the greeting. With no extra word, you see the usage line.

The same steps, written as a program

Read the three steps again. process.argv[2] is the extra word. The if chooses the missing-word path or the greeting.

What you should see
Hello, Ada.

What each line is saying

  1. const name = process.argv[2];Store the first extra word. If you typed none, name is undefined, which means missing.
  2. if (!name) {This path runs when the word is missing.
  3. console.log("Usage: node greet.mjs <name>");Show a tiny manual. The brackets mean “a name goes here.”
  4. console.log(`Hello, ${name}.`);The word was present. Drop it into the greeting. The backticks allow that drop-in.

Try it

The box starts with Ada and Lagos. Press Run. You should see a hello that names both. Clear the words and run again. You should see a usage line.

Practice. The first extra word is argv[2]. The next is argv[3].

Easy to mix up

  • process.argv[0] is Node.js itself. Your first word is [2].
  • Every extra word arrives as text. The number 3 arrives as "3" until you turn it into a number with Number.
  • Keep the changing value in the command. A second copy written inside the file will drift away from it.

Remember

process.argv is the command, split into words. Your first extra word is index 2. Check that it exists before you use it.
