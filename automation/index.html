Layer 02

JavaScript for practical automation

This layer points the fundamentals at small jobs on your computer: the terminal, npm, arguments, environment variables, files, paths, JSON, text, lists, dates, modules, promises, async, HTTP, and a script that writes a report.

The practice boxes use simple stand-ins, such as readFile, so you can try the idea in the page. The lesson text shows the real Node.js spelling for when you are ready to save a file.

  1. 01
    The terminal

    The terminal is where you send short commands to your computer.

  2. 02
    Running JavaScript files with Node.js

    node runs a file. The exit code tells the shell whether it worked.

  3. 03
    npm and package.json

    npm installs packages. package.json lists them.

  4. 04
    Command-line arguments

    process.argv is the list of words you typed after node.

  5. 05
    Environment variables

    The environment is a place for settings, including secrets.

  6. 06
    Reading and writing files

    A script can save text and read it back.

  7. 07
    Paths and folders

    A path is an address. node:path builds one that works on your system.

  8. 08
    JSON

    JSON is a text format for data. Parse it into values. Stringify values into text.

  9. 09
    Cleaning up text

    Real text arrives with spaces, odd case, and separators.

  10. 10
    Transforming lists

    map, filter, and reduce build new arrays from old ones.

  11. 11
    Dates and times

    Date holds an instant. Intl formats it for people.

  12. 12
    Modules

    export shares a function. import uses it from another file.

  13. 13
    Promises

    A promise is a value that will arrive, or fail, later.

  14. 14
    async and await

    await pauses one function until a promise settles.

  15. 15
    HTTP requests with fetch

    fetch asks a server for a response. Check response.ok.

  16. 16
    Logs and exit codes

    Logs are for people. Exit codes are for the shell.

  17. 17
    A script that turns a list into a report

    Read lines, clean them, write a dated report, exit with a code.
