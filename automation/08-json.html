Layer 02 · Lesson 8 of 17

JSON

One idea. JSON is text for data. Stringify writes that text. Parse reads it back.

Start with a normal day

A friend asks what is in a box. You do not hand over the box. You write a label: a name, and a number of cups.

The label is flat text. It can sit in a file. It can travel to another computer. Someone who reads the label builds a new box with the same facts. The label lists facts only. It cannot carry an action.

New words

The file below writes a label and reads it back. The practice box reads a list of tasks from a file. These words cover both.

JSON
Text that holds data, such as text, numbers, lists, and objects. It looks a little like JavaScript. The rules are stricter.
stringify
JSON.stringify turns a value into JSON text. The result is text, not an object.
parse
JSON.parse reads JSON text and builds a value again. It accepts text only.
const
A name for a value. person, raw, again, and tasks are names.
object
One record with named blanks, inside { }. In the sample, the blanks are name and cups.
key
The name of a blank, such as name or cups. In JSON every key wears double quotes. In the JavaScript line, name needs no quotes.
string
Text. After stringify, raw is text. You cannot write raw.cups on text.
dot
again.cups means the cups blank on the object named again.
array
A list in order, inside [ ]. The practice file holds two tasks.
index
The number of a spot in a list. The first spot is 0. tasks[0] is the first task.
readFile
In the practice box, this reads a named file and returns its text. The file is tasks.json.
double quotes
The " marks. JSON keys and JSON text use them. Single quotes are not allowed.
trailing comma
A comma with nothing after it. A comma just before ] is one. JavaScript often allows it. JSON does not.
console.log
Show a value on the screen.

The steps, before any program

  1. Write down one person: the name Asha, and 2 cups.
  2. Turn that record into one line of JSON text.
  3. Show the line.
  4. Read the line back into a new record.
  5. Show the number of cups.

The trip through text keeps the number. Cups stays the number 2. It does not become the text "2".

The same steps, written as a program

Read the five steps again. The file turns one record into text, then builds a new record from that text.

What you should see
{"name":"Asha","cups":2}
2

What each line is saying

  1. const person = { name: "Asha", cups: 2 };An ordinary JavaScript object. The key name does not need quotes here.
  2. const raw = JSON.stringify(person);Make one string of JSON. Inside that string, the keys wear double quotes. raw is text. You cannot write raw.cups.
  3. console.log(raw);Show the label. It is one string.
  4. const again = JSON.parse(raw);Read the label and build a new object.
  5. console.log(again.cups);Show the cups blank on the new object. It is the number 2.

Try it

Run the box. It prints the first task, Buy milk. Then add a comma just before the ] in tasks.json and run again. Read the error. Take the comma back out.

Practice. Print the first task. Do not leave a comma before the ].

Easy to mix up

  • JSON.parse eats text. Do not parse an object you already have.
  • A trailing comma, or single quotes, is allowed in many JavaScript objects. Both are forbidden in JSON.
  • JSON.stringify keeps facts it can write as text. It drops a function stored on an object. A function is a saved action. It also drops a blank on an object when that blank is undefined, which means no value.
  • JSON has no comments. A // note in the text makes parse fail.

Remember

JSON is strict text for data. JSON.stringify writes it. JSON.parse reads it. Keys use double quotes. The text holds values, not actions.
