JSON

One idea. JSON is text for data. Parse turns that text into values.

The idea

JSON is a text format for numbers, strings, booleans, arrays, and objects. It looks like JavaScript and it is stricter. Keys are in double quotes. There are no comments, no trailing commas, and no functions.

JSON.stringify(value) turns a value into JSON text. JSON.parse(text) turns JSON text back into a value. Files and web APIs use this pair constantly.

Why it matters

Configuration files, API responses, and Playwright’s stored login state are JSON. You will read them with parse and write them with stringify. Treating JSON as “JavaScript you can paste anywhere” causes syntax errors that look unfair until you know the extra rules.

A picture to hold

A shipping label. Your objects are the contents of the box. JSON is the flat label that can travel through a file or across the network. stringify prints the label. parse reads the label and rebuilds the contents. The label cannot describe a function, because a function is a behavior, not cargo.

A small example

What you should see
{"name":"Asha","cups":2}
2

Line by line

  1. const person = { name: "Asha", cups: 2 };An ordinary JavaScript object. The key name did not need quotes in JavaScript.
  2. const raw = JSON.stringify(person);Produce a string of JSON. Inside that string, keys wear double quotes. raw is text, not an object. You cannot write raw.cups.
  3. console.log(raw);Print the label. It is one string.
  4. const again = JSON.parse(raw);Read the label and build a new object.
  5. console.log(again.cups);The new object has a number property cups. The trip out to text and back preserved it.

Try it yourself

Run it and print the first task. Then add a comma before the ] and run again. Read the error, then remove the comma.

Practice. JSON uses double quotes and does not allow a trailing comma.

Common mistakes

  • Calling JSON.parse on an object that is already parsed. Parse eats text.
  • Trailing commas and single quotes in a .json file. Legal in many JavaScript objects. Illegal in JSON.
  • Expecting stringify to keep functions or undefined object properties. It drops them.

Recap

JSON is strict text for data. JSON.stringify writes it. JSON.parse reads it. Keys use double quotes, and the format holds values, not functions.
