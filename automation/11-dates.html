Dates and times

The idea

A Date is a single moment in time. new Date() is “now,” according to the computer’s clock. toISOString() prints that moment in UTC, the shared clock used by files and APIs, in a form like 2026-09-27T18:04:00.000Z.

Intl.DateTimeFormat prints the same moment for humans, in a language and a style you choose. Building a date from parts is the sharp edge: in the Date constructor, months are numbered 0 through 11. January is 0.

Why it matters

Reports need a date. Tests that mean “yesterday” break at midnight if you build the string by hand. Store an instant. Format it at the edge, when a human will read it.

A picture to hold

A timestamp is a pin on a world clock. UTC is the world clock. Your laptop’s time zone is a local poster of that same pin. Intl paints the poster. The pin does not move when you change the poster’s language.

A small example

The ISO line is for machines. The formatted line follows your computer’s time zone and will look like Sep 27, 2026, 2:04 PM. January is month 0 if you write new Date(2026, 0, 27).

Line by line

  1. const now = new Date();Capture the current instant. Calling it twice a second later gives a different instant.
  2. console.log(now.toISOString());Print UTC in ISO form. The Z means the offset is zero, which is UTC.
  3. new Intl.DateTimeFormat("en", {Make a formatter. "en" is English. The options choose a medium date and a short time.
  4. }).format(now);Apply the formatter to the instant. This returns a string. It does not change now.

Try it yourself

Print today’s ISO string. Then create new Date(2026, 0, 27) and format it. Confirm you landed in January, not February. Write the month number you meant in a comment next to the 0, so future you remembers.

Common mistakes

  • Treating month 1 as January. In this constructor, 1 is February.
  • Comparing dates by their formatted strings. Two locales format the same instant differently. Compare ISO strings, or compare getTime(), which is milliseconds.
  • Building “today” by slicing a local string and then parsing it back. Take new Date() and format once, at the end.

Recap

new Date() captures an instant. toISOString is the machine spelling, in UTC. Intl.DateTimeFormat is the human spelling. Constructor months start at 0.
