Dates and times

One idea. A Date is one moment. You can print it for a machine or for a person.

Start with a normal day

You buy one train ticket. The office also writes a filing slip for that same departure. The slip uses a strict order. The ticket uses ordinary words.

Rewording the ticket does not move the train. The departure stays one moment.

New words

const and console.log mean the same as before. The program prints two papers for the current moment. The practice box builds 27 January 2026 and prints the month name.

Date
One moment. new Date() is now. new Date(2026, 0, 27) is a year, a month, and a day. In that form the month starts at 0, so January is 0.
toISOString
The machine line for that moment. The year comes first, then T, then the time. Z at the end means UTC, the shared world clock. It looks like 2026-09-27T18:04:00.000Z.
DateTimeFormat
Turns the same moment into a sentence for people. en means English. dateStyle: "medium" looks like Sep 27, 2026. timeStyle: "short" looks like 2:04 PM. format returns that text and leaves the moment alone.
month
Ask for the month name only. "long" is the full word, such as January. slice(0, 10) keeps the first ten characters of the machine line, which is the date.

The steps, before any program

  1. Take the current moment.
  2. Print the machine line for that moment.
  3. Build an English formatter with a medium date and a short time.
  4. Print the human sentence for the same moment.

The moment does not change. Only the spelling changes.

The same steps, written as a program

Read the four steps again. The first line stores the moment. The second line prints the machine spelling. The middle lines build the human sentence. The last line prints it. A machine line looks like 2026-09-27T18:04:00.000Z. A human line looks like Sep 27, 2026, 2:04 PM. Your clock picks the numbers.

What each line is saying

  1. const now = new Date();Store the current moment under the name now. Ask again a second later and you get a different moment.
  2. console.log(now.toISOString());Print the machine line. The Z at the end means the world clock.
  3. const formatted = new Intl.DateTimeFormat("en", {Start a stored name, formatted. Build an English formatter. The brace opens its settings. The name receives the sentence, not the formatter.
  4. dateStyle: "medium",Ask for a middle-length date, such as Sep 27, 2026.
  5. timeStyle: "short",Ask for a short time, such as 2:04 PM. The clock where you are picks the hour.
  6. }).format(now);Close the settings. Turn the moment into a sentence and store that sentence as formatted. now does not change.
  7. console.log(formatted);Print the human sentence.

Try it

Press Run. The second line should say January. The month number in the box is 0. Change 0 to 1 and that line moves to February.

Practice. Month 0 prints January.

Easy to mix up

  • Month 0 is January. Month 1 is February. In new Date(2026, 0, 27) the middle number is not the calendar month.
  • Do not check two moments by comparing human sentences. Another language spells the same moment differently. Compare the machine lines.
  • toISOString uses the world clock. A date built from parts starts at midnight where you are. The machine day can be the day before. Do not cut up a human sentence and read it back as a moment. Take new Date() and format once, at the end.

Remember

A Date is one moment. toISOString writes the machine line, on the world clock. Intl.DateTimeFormat writes the human sentence. When you pass a month number, January is 0.
