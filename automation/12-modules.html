Modules

One idea. A module is a file that shares a recipe. export offers it. import uses it.

Start with a normal day

A bakery keeps a recipe in the kitchen. The counter offers a short list. A customer may ask for a loaf. The customer may not take a private tool from the kitchen.

A module is that kitchen, written as a file. export offers a recipe. import uses it. The .mjs ending tells Node.js the file is that kind of file.

New words

money.mjs keeps the price recipe. shop.mjs uses it. The practice box also offers a recipe named half.

module
A file that shares a recipe. Other files can use what it offers. The rest of the file stays private.
export
Offer a recipe. Other files can import that name. A recipe with no export stays in the file.
function
A named recipe. You write the steps once. You run them when you use the name. priceWithTax takes a price. half takes a number.
return
Hand a value back, and stop the recipe there.
Math.round
Round to the nearest whole number. Math is the set of number tools. round is one of them. Multiply by 100, round, then divide by 100. That keeps the cents.
import
Use a recipe another file offers. import { priceWithTax } asks for that one name.
{ }
On an import line, the braces wrap the names you want. { priceWithTax } asks for one name. { half } asks for the other. These are not the braces around a recipe body.
from
The file that offers the names. It comes after the braces on the import line.
./
The folder this file is already in. ./money.mjs is the money file beside shop.mjs. It is not the folder your terminal is in.
../
One folder up. It is the folder that holds the folder this file is in.
.mjs
The ending on the file name. It tells Node.js the file is a module. Write it in the import path. Node.js will not add it for you.
console.log
Print one line so you can see it.

The steps, before any program

  1. In money.mjs, write a recipe that adds ten percent and rounds to cents.
  2. Offer that recipe with export.
  3. In shop.mjs, import the recipe from the file beside it.
  4. Use the recipe with 4, and print the result.

The shop file does not copy the recipe. It uses the offered name.

The same steps, written as a program

Read the four steps again. The first box is money.mjs. It offers the recipe. The second box is shop.mjs. It imports that recipe and prints the price of 4 with tax.

What you should see
4.4

What each line is saying

  1. export function priceWithTax(price) {Write a recipe named priceWithTax and offer it. price is the number you pass in. Other files may import this name.
  2. return Math.round(price * 1.1 * 100) / 100;Add ten percent. 1.1 means the price plus a tenth. Shift the cents up by 100, round to a whole number, then shift back. Hand that number back.
  3. import { priceWithTax } from "./money.mjs";Use the offered name from the file beside this one. The path starts at shop.mjs. The .mjs ending is required.
  4. console.log(priceWithTax(4));Run the recipe with 4 and print the result. The recipe still lives in money.mjs.

Try it

The money file also offers half. The shop file imports half and prints half(9). Press Run. You should see 4.5.

Practice. half(9) prints 4.5.

Easy to mix up

  • The import path needs the file ending. ./money is not enough. Write ./money.mjs.
  • ./ means beside this file. ../ means one folder up. A path from the project root is a different address.
  • Offer the recipes another file uses. A name with no export stays in the file. Another file cannot import it.

Remember

A module is a file that shares a recipe. export offers it. import uses it. .mjs tells Node.js the file is that kind of file.
