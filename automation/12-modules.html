Modules

One idea. export shares a name. import uses that name from another file.

The idea

A module is a file that shares some of its names and keeps the rest private. export marks a name as public. import brings that name into another file.

The other file is named with a relative path starting with ./. You include the .mjs ending. Node.js does not guess file endings for your own modules.

Why it matters

One file that does everything becomes hard to read and risky to change. Playwright projects split the same way: config in one file, tests in others, shared helpers in others. The mechanism is export and import.

A picture to hold

A shop counter. The workshop behind the counter can be messy. The counter (export) is the short list of what customers may ask for. Another file is a customer. It does not reach over the counter and grab a private tool.

A small example

What you should see
4.4

Line by line

  1. export function priceWithTax(price) {Define a function and make it public. Other files may import this name.
  2. return Math.round(price * 1.1 * 100) / 100;Ten percent tax, rounded to cents. Math.round rounds to the nearest integer, so the * 100 and / 100 shift the decimal.
  3. import { priceWithTax } from "./money.mjs";Ask for that public name from the neighboring file. The path is relative to shop.mjs, not to the shell’s current folder.
  4. console.log(priceWithTax(4));Call it as if it lived here. The function still runs in the module that defined it.

Try it yourself

Add export function half in money.mjs. Import half in shop.mjs and print half(9). You should see 4.5.

Practice. If shop imports a name money does not export, the box says so.

Common mistakes

  • Forgetting the file ending in the import path. ./money is not enough for your own files.
  • Using a path from the project root out of habit. ./ means “beside this file.” ../ means “the parent of this file’s folder.”
  • Exporting everything “just in case.” Export the functions a caller actually needs.

Recap

export makes a name public. import takes that name from a relative path that includes the file ending. Everything else in the file stays private.
