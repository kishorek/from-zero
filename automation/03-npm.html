npm and package.json

One idea. package.json is the shopping list. npm refills node_modules from that list.

The idea

A package is someone else’s code, published so you can install it. npm is the tool that downloads packages. It comes with Node.js.

package.json is a file that describes your project: its name, and the packages it needs. npm init -y creates a starter package.json in the current folder. npm install some-package downloads that package into a node_modules folder and writes the name into package.json.

dependencies are packages your program needs when it runs. devDependencies are packages you need while building or testing. Playwright’s test runner belongs in devDependencies. package-lock.json records the exact versions npm installed. Commit it with the project. Do not commit secrets.

Why it matters

You will not write a browser from scratch. You will install Playwright. Knowing what package.json and node_modules are keeps that install from looking like clutter.

A picture to hold

A shopping list on the fridge (package.json) and the grocery bags in the kitchen (node_modules). The list is small and worth keeping. The bags are large and can be refilled from the list with npm install. You do not mail the bags to a friend. You mail the list.

A small example

Run the shell commands in an empty project folder. The JavaScript reads your package.json back, which is a normal file full of text.

node:fs is a built-in module. The node: prefix marks “this comes with Node.js, not from npm.” import.meta.url is the address of the current file, so the script finds package.json beside itself even if you launched node from another folder.

Line by line

  1. npm init -yWrite a default package.json in the current folder. -y accepts the defaults without a questionnaire.
  2. import { readFileSync } from "node:fs";Take one function, readFileSync, from Node’s file tools. Sync means the line waits until the file has been read.
  3. const raw = readFileSync(new URL("./package.json", import.meta.url), "utf8");Read the file as text. utf8 is the character encoding, the right choice for JSON and for English source code.
  4. console.log(raw);Print the JSON text. You will parse it properly in the JSON lesson. Today, seeing the text is enough.

Try it yourself

The file box is a tiny package.json. Change the description, then run. Your sentence should show up in the print.

Common mistakes

  • Editing files inside node_modules. The next install overwrites them. Your code stays outside that folder.
  • Forgetting to share package.json and then wondering why a classmate’s npm install does nothing useful.
  • Installing a package you only needed for one experiment and leaving it forever. The list is yours to edit.

Recap

package.json is the project list. npm fills node_modules from that list. Built-in tools use the node: prefix and do not need an install.
