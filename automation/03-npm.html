npm and package.json

One idea. package.json is the shopping list. npm refills the grocery bags from that list.

Start with a normal day

A shopping list stays on the fridge. The grocery bags are large. You can throw the bags away and refill them from the list.

You mail a friend the list. You do not mail the bags.

New words

The commands create the list. The file then reads that list back as ordinary text.

package
Someone else’s code, published so you can install it.
npm
The tool that downloads packages. It comes with Node.js.
package.json
The shopping list: the project’s name, and the packages it needs.
npm init -y
Create a starter list in the current folder. -y means “yes, use the defaults,” so it skips the questionnaire.
node_modules
The grocery bags. npm puts downloaded packages here. The next install can refill this folder, so you do not edit files inside it.
dependencies
Packages the program needs when it runs.
devDependencies
Packages you need only while building or testing.
node:fs
File tools that come with Node.js. The node: prefix means “this is built in. It does not come from npm.”
readFileSync
Read a whole file and wait until that read is finished. The practice box uses the shorter name readFile for the same idea.
import
Take a recipe from another file. This file is .mjs because it uses import.
utf8
The usual way to read English and JSON text.

The steps, before any program

  1. In a project folder, create a starter shopping list.
  2. Ask npm for its version, so you know the tool is there.
  3. From a JavaScript file, read package.json as text and show it.

Seeing the text is enough today. A later lesson turns that text into values.

The same steps, written as a program

Read the three steps again. The first box is the terminal. The second box is the file that reads the list. import.meta.url is the address of this file, so it finds package.json beside itself.

What each line is saying

  1. npm init -yWrite a default package.json in this folder. You type this in the terminal.
  2. import { readFileSync } from "node:fs";Take the “read a file and wait” recipe from Node’s built-in file tools.
  3. const raw = readFileSync(new URL("./package.json", import.meta.url), "utf8");Read the shopping list beside this file, as text, and store it under raw.
  4. console.log(raw);Show that text.

Try it

The box has a tiny package.json. Change the description, then press Run. Your sentence should appear in the print.

Practice. readFile in this box is the stand-in for readFileSync.

Easy to mix up

  • Edit your own files. The next install overwrites anything you change inside node_modules.
  • Share package.json. A classmate runs npm install and the list refills their bags.
  • A package you only needed once can leave the list. The list is yours to edit.

Remember

package.json is the list. npm fills node_modules from that list. Tools with the node: prefix come with Node.js and do not need an install.
