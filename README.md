# From Zero

A beginner course in three layers: programming fundamentals, practical JavaScript, and Playwright.

Open `index.html` locally, or read it on the web at [kishorek.github.io/from-zero](https://kishorek.github.io/from-zero/).

The pages are plain HTML, CSS, and a small script. Nothing has to be installed to read them. The code examples run with Node.js 20 or newer. Playwright lessons use `@playwright/test`.
